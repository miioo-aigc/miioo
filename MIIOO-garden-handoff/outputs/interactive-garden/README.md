伞形白花精修：由规则的 31 根长辐条改为 27 个不均匀复伞形分枝，缩短共同支撑段，调整浅穹顶高差与前后深度。每簇含 9–17 朵大小、朝向和色调不同的小花，补充细花梗与少量花蕊，细化分枝并降低亮度。小花花瓣厚度和皱褶随尺寸缩小，避免微型花瓣沿用大花的厚度。每个分枝记录独立弹簧状态，在共同基点作小幅旋转后叠加整株茎弯曲，法线同步旋转；短阵风衰减为 0.23 秒。所有分枝依旧合并成 5 个几何组。该版本为程序化植物，不是摄影扫描资产；局部材质和轮廓仍与摄影背景存在差距。preview-umbel-refined.png 为当前桌面预览。

蒲公英精修：185 簇冠毛记录独立朝向、柔软度、相位及弹簧阻尼状态，合并为同一个 LineSegments 几何，逐簇更新角度属性。种子基部固定，种柄与冠毛整体旋转保持连接，末端细毛叠加小幅高频颤动。受风形变先于整株茎弯曲计算，使用独立着色器缓存标识。蒲公英阵风衰减常数为 0.19 秒，茎刚度提高并保留轻微反向回摆；冠毛响应比花茎快。减少动态效果时关闭常态风和颤动。白色雏菊参数不变。此为受风运动近似，无流体求解、种子脱落或碰撞。五株几何导出检查通过，蒲公英自定义属性有限且数量一致；浏览器加载及扫过检查无错误或警告。preview-dandelion-refined.png 为本轮桌面预览。

雏菊短阵风调整：局部阵风衰减时间常数由 0.48 秒降至 0.16 秒；花茎恢复刚度提高并允许一次轻微反向回摆，花瓣刚度由 165/柔软度提高至 440/柔软度，阻尼从 23 调至 17。降低花茎慢位移对花瓣的持续压迫，增强短阵风直接作用。固定步长脉冲模拟中，花茎在约 0.6 秒出现轻微反向回摆、1 秒附近收稳；具体结果随扫过速度与花瓣朝向变化。浏览器阵风检查无错误或警告。此项只调整白色雏菊。

花瓣动画修复：为独立雏菊花瓣与普通植物材质分配不同的程序缓存标识，防止复用不含花瓣弯曲的程序；将瓣片弯曲置于整株弯曲之前，法线按同样顺序处理。花瓣直接响应局部阵风并保留小幅颤动，避免仅跟随已平滑的花茎位移导致响应不明显。已用桌面局部截图检查鼠标扫过前后的形态变化；浏览器无错误或警告。

最新雏菊精修：white-daisy 的两圈 24 片花瓣分别建模，记录独立瓣根、方向、弯曲平面、柔软度和阻尼状态。花瓣以弧形中心线弯曲，固定瓣根并保持中心线长度；表面法线跟随旋转，再叠加整株花茎弯曲。朝向决定压力，阵风带来小幅瓣尖颤动，阻尼让花瓣平稳恢复。这是简化梁弯曲模型，无空气流体求解或花瓣碰撞。其他植物沿用原运动方式。浏览器加载和阵风检查未报告错误；24 个花瓣坐标系与阻尼恢复通过数值检查，五株模型的几何与 UV 检查通过。models/ 已同步静态几何，运行时动画着色器仍在 garden-3d.js。preview-daisy-petals.png 为当前预览。

植物改用根部固定的弧形花茎弯曲，花头上部以共同支点作刚性旋转，避免按顶点高度平移造成花瓣拉伸。移除额外水平转向；采用接近临界阻尼的恢复，短花茎降低常态摆幅与阵风上限。当前为受风弯曲近似，未实现每片花瓣的独立物理模拟。仅保留常态微风与鼠标经过的短阵风，无按住拖动交互。

本轮材质：botanical-materials.js 为每片叶与花瓣提供独立 UV 对应的程序化色素、叶脉、细纹、凹凸和粗糙度贴图，并根据实时方向光计算薄片背光散射近似。使用暖主光、冷背光和弱补光，根部颜色渐暗以衔接苔藓。贴图在本地生成，无外部请求。材质着色器与弯曲着色器串联，保留拖动回弹；减少动态效果设置也禁用鼠标转向。

背景和其余小植物仍是摄影图；这不是全场景三维重建。程序化模型还没有摄影扫描纹理、自阴影、体积次表面散射或植物间碰撞。薄片散射不等于完整 SSS，摄影级材质与自然形态仍需继续精修。当前仅考虑桌面。preview-materials.png 为本轮截图。五株模型的有限顶点、三维深度及表面 UV 已检查，浏览器未报告着色器错误或警告。

当前版本使用本地照片和 Three.js，将蒲公英、两株白花、两朵前景橙花提取成 5 个透明植物图层。根部固定，鼠标经过花头时轻推，按住拖动可弯曲，释放后通过弹簧阻尼回弹；不同植物具有不同刚度。背景保持稳定。支持微风、减少动态效果设置及 WebGL 静态回退。无运行时外部请求或 API key。

这是桌面优先的 2.5D 摄影分层原型，未进行手机适配。具有独立植物网格和背景补洞，但仍无真实三维碰撞、立体叶片或可绕行视角。细小花丝边缘和植株交叠仍有照片提取的局限。背景补洞使用用户已配置的图像 API 生成候选，仅将指定植物原位置附近的区域合回原图。提取和合成脚本位于工作区 work/split_garden.py。
