这五个 .three.json 文件是可由 THREE.ObjectLoader.parse() 读取的植物模型，包含几何、材质和植物元数据，未包含背景照片。由 plant-models.js 使用确定性随机种子生成，通过工作区 work/export-plants.mjs 导出。

植物包括：蒲公英、伞形白花、白色雏菊、两株橙花。花茎为圆截面曲线管，叶片为曲面网格，花瓣含正反表面和侧边。蒲公英冠毛使用三维线段，种子使用网格。模型具有前后深度，可以独立旋转。

文件保存静止形态及程序化 DataTexture 贴图。主页中的动态弯曲、根部渐暗由 garden-3d.js 注入着色器，薄片背光散射由 botanical-materials.js 注入；导出 JSON 不包含这些运行时着色器，独立使用时需重新挂接。

这些是程序化植物资产，并非摄影扫描资产；当前未使用扫描 PBR 纹理、体积次表面散射、自阴影或植物间碰撞。主页的背光为薄片表面散射近似。
