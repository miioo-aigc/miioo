# 桌面花园流畅度验证

日期：2026-10-29。测试设备为 MacBook Air，Apple M4（10 核 CPU、10 核 GPU）、24 GB 内存，macOS 27.2；浏览器为 Codex 内置浏览器，具体版本未确认。帧时间为浏览器帧间隔，不是 GPU 独立耗时。

## 前后样本

纯背景页，视口 1280×720、绘制像素比 1.00，各为 120 帧窗口样本：

| 场景 | FPS | 帧间隔中位数 | 帧间隔 P95 | 绘制调用 | 三角形 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 优化前，常态 | 60.0 | 16.70 ms | 17.30 ms | 15 | 25,492 |
| 优化前，鼠标横扫后 | 60.0 | 16.70 ms | 17.40 ms | 15 | 25,492 |
| 优化后，常态 | 60.0 | 16.70 ms | 17.40 ms | 15 | 约 19,444 |
| 优化后，鼠标横扫后 | 60.0 | 16.70 ms | 17.40 ms | 15 | 约 20,116 |

优化前后均记录到 8 次横扫交互。优化后只提交活跃飘叶，因此三角形数随场景时刻和阵风变化；这些样本不能单独证明所有设备的帧率提升。首页优化后在同一视口、像素比 1.00 时为约 60 FPS，中位数 16.70 ms、P95 17.30 ms。首页优化前采样的像素比是 1.50，不能作为严格的前后对照。

同一设备上，首页工作台模糊开启与临时关闭时的中位帧间隔均为 16.70 ms，P95 分别为 17.20 ms、17.30 ms；此样本未显示显著差别，因此保留现有模糊效果。

## 功能复验

- 首页通过临时滚动测试夹具将花园完全移出视口：1.2 秒内帧数及动画时间保持不变；滚回后继续增长。
- 纯背景页暂停时帧数与动画时间保持不变，播放后继续；横向扫鼠标可触发阵风。
- 模拟 WebGL 不可用时显示静态回退；减少动态效果时默认暂停；图形上下文丢失后状态由 ready → fallback → ready。
- 视口由 1280×720 改为 1440×900 后画面正常、帧数继续增长；纯背景截图未见明显植物断连。
- JavaScript 语法检查通过；飘叶实例另经 3,600 帧模拟，覆盖反复阵风、回收、显隐及释放。

主动模拟 WebGL 不可用时浏览器会记录对应的上下文创建错误；临时 iframe 导航测试还出现一次来源未确定的 MutationObserver TypeError。常规画面的渲染和上述功能检查通过，但未据此断言所有测试过程零日志。

尚未完成其他浏览器、普通办公集显、多设备、长时间内存趋势及实际 30 Hz / 高刷新率屏幕测试。画质试探与慢帧恢复策略需要在这些环境中进一步验证；这些本机样本不保证所有设备稳定 60 FPS。
