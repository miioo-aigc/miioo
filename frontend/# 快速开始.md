OneLinkAI 采用全球通用的 OpenAI 标准接口协议，无论您是深度开发者还是效率工具爱好者，都能在几分钟内实现无缝集成。

### 1️⃣ 极简原生调用：HTTP 请求
如果您不需要复杂的 SDK，可以直接使用 cURL 或常用的请求库。OneLinkAI 优化了全球边缘加速网关，确保您的 API 请求秒级响应。

- API 地址： https://api.onelinkai.cloud/v1/chat/completions
- 认证方式： 在 Header 中携带您的 OneLinkAI API Key
  
代码示例 (Python / JS / cURL)
```python
import requests
import json

# 只需更换 URL 和 API Key，即可调用全球最强模型
url = "https://api.onelinkai.cloud/v1/chat/completions"
headers = {
    "Authorization": "Bearer <YOUR_ONELINKAI_KEY>",
    "Content-Type": "application/json"
}

payload = {
    "model": "glm-5.1", # 亦可切换为 qwen3.7-max, deepseek-v4-pro 等
    "messages": [{"role": "user", "content": "用三句话形容 AI 对未来的改变"}],
    "stream": True # 强烈建议开启流式传输，体验丝滑响应
}

response = requests.post(url, headers=headers, data=json.dumps(payload))
print(response.text)

fetch("https://api.onelinkai.cloud/v1/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer <YOUR_ONELINKAI_KEY>",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    model: "glm-5.1",
    messages: [{role: "user", content: "你好！"}]
  })
}).then(res => res.json()).then(console.log);
```

### 2️⃣ 深度集成：使用官方 SDK (OpenAI)
OneLinkAI 与 OpenAI 生态高度兼容。在现有项目中，您无需修改任何业务逻辑，只需重定向 base_url 即可完成从高价官方版到高性价比 OneLinkAI 的平滑切换。

Python 示例

```javascript
from openai import OpenAI

# 注入 OneLinkAI 的灵魂，享受多云聚合的稳定性
client = OpenAI(
    api_key="<YOUR_ONELINKAI_KEY>",
    base_url="https://api.onelinkai.cloud/v1" # 关键步骤：指向 OneLinkAI 节点
)

completion = client.chat.completions.create(
    model="glm-5.1",
    messages=[
        {"role": "system", "content": "你是一个专业的翻译官"},
        {"role": "user", "content": "OneLinkAI makes AI integration so easy."}
    ],
    temperature=0.7,
)

print(completion.choices[0].message.content)
```

### 🔧 配置小贴士：
在大多数第三方客户端中，设置方式通常如下：
1. API 域名 (Base URL)： https://api.onelinkai.cloud
2. 路径追加： 某些软件需要完整路径，请尝试 https://api.onelinkai.cloud/v1 或 https://api.onelinkai.cloud/v1/chat/completions
3. API Key： 填写在 OneLinkAI 控制台生成的秘钥。
