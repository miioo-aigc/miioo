# 视频播放控制栏

2026-10-29：统一组件已实现，待手动验收。

剪辑中央预览及创作、分镜、通用媒体、成片视频详情共用 ui/VideoPlayerBar。单视频详情通过 MediaVideoPlayerBar 监听媒体事件，接入播放进度、音量和静音；播放恢复仍由宿主负责。剪辑直接提供整条时间线状态。

- 双排布局，底部80px常驻，水平内边距16px。背景复用 surface-content-area，时间使用次要文字色及等宽数字。
- 上排仅播放/暂停、当前时间/总时长、音量；下排独立进度条。用户明确删除全屏和更多菜单，不再提供其内部功能；详情本身的下载按钮保留。
- 音量滑杆在悬停或聚焦时展开，圆点左侧纯白、右侧灰色；静音时左侧填充归零。进度条使用同样填充规则，滑块默认隐藏，悬停或聚焦显示。
- 空时间线保留控制栏并禁用操作。剪辑播放按钮禁用回车和白色焦点外框；时间轴空格播放保留。画布点击暂停并选中素材，不启动播放。
- 创作详情保留画面点击播放及500毫秒中央反馈。其他详情保留各自原有自动播放策略。媒体事件订阅在切换视频和卸载时清理。
- 组件不读取业务 Store；剪辑音量仅控制试听，不修改素材音量或导出参数。

2026-10-29 部分验收后修正：详情弹窗通过 displayScale 抵消整体缩放对按钮及图标的放大；播放图标实际20px、音量图标实际22px，与剪辑页一致。仅修正播放栏按钮尺寸，不改变弹窗整体缩放。待手动复验。

2026-10-29：音量按钮默认80%白色，悬停和按下100%。共享栏新增 trailingControl 展示插槽，剪辑宿主在音量右侧复用 Select 提供流畅优先/画质优先，详情不显示此选择器。
