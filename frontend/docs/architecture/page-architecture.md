# 页面架构规范

> 文档类型：页面入口、业务区块和页面状态规则
> 最后更新：2026-07-15

## 1. 页面入口应该负责什么

页面入口是页面级编排层，负责：

- 读取路由参数和页面上下文；
- 持有页面级状态、加载态、错误态和选中项；
- 调用 API、Store 或页面 Hook；
- 组织页面区块并连接区块之间的回调；
- 管理页面生命周期、副作用、任务轮询和跨区块缓存；
- 保持路由、权限和页面级业务流程。

页面入口不应该承载所有具体 JSX。它应当让读者一眼看出页面由哪些区块组成。

## 2. 页面目标结构

推荐的页面入口形态如下：

```jsx
export default function CreationPage() {
  const pageState = useCreationPage();

  return (
    <CreationLayout>
      <CreationHeader {...pageState.header} />
      <CreationSidebar {...pageState.sidebar} />
      <CreationWorkspace {...pageState.workspace} />
      <CreationFooter {...pageState.footer} />
    </CreationLayout>
  );
}
```

这只是结构示例，不要求把所有状态机械地塞入一个 `useCreationPage`。复杂页面可按职责使用 `useCreationData`、`useCreationActions`、`useCreationSelection` 等多个 Hook；页面仍然负责组合它们。

## 3. 页面入口不应继续包含

- 大量按钮 JSX 或重复的原生 `<button>` 样式；
- 复杂弹窗、确认框和遮罩内部实现；
- 具体表单字段、选择器菜单和重复校验结构；
- 很长的卡片、列表项、表格行或媒体结果结构；
- 多处重复的加载态、错误态、空态和 Toast 视觉；
- 大量 API 请求细节、URL 拼接、header 和响应字段兼容转换；
- 大量只能服务于某个子区块的局部工具函数；
- 把整个页面状态对象无差别透传给所有子组件。

## 4. 状态和数据边界

| 内容 | 推荐位置 |
|---|---|
| 页面选中项、面板开关、页面级加载态 | 页面或页面 Hook |
| 跨页面业务状态 | `src/stores/` |
| 请求 URL、方法、鉴权和响应适配 | `src/api/` |
| 纯数据转换、字段兼容和参数组装 | 业务域工具或 API 适配工具 |
| 纯展示状态和局部交互 | 业务组件内部 |
| 跨页面无业务逻辑的视觉状态 | `components/ui/` |
| 任务轮询循环及其副作用 | 页面或业务 Hook；读取适配可抽成纯函数 |

拆分时先保留页面级副作用边界，再逐步抽取纯展示、纯转换和稳定交互。不要为了降低行数把所有请求和状态整体搬进一个超长 Hook。

## 5. 页面迁移流程

1. 先阅读顶部结构索引；没有索引时先建立代码地图，不直接大范围移动。
2. 盘点状态、Store、API、effects、定时器、ref、props、回调和闭包依赖。
3. 列出区块边界：先纯展示区块，再交互区块，最后处理 Hook 和动作。
4. 每次只迁移一个明确区块，保持原 props、回调、接口参数和视觉 Token。
5. 迁移后全局搜索旧定义、旧导入、失效回调和未定义变量。
6. 检查 import/export、目录入口和循环依赖。
7. 更新文件结构索引、组件资产清单和迁移记录。
8. 执行定向检查、构建、架构检查和关键页面回归，再开始下一块。

## 6. 页面规模警告线

页面入口建议不超过 300 行；单个业务区块建议不超过 400 行；Hook 建议不超过 300 行；单个函数建议不超过 50 行。它们是识别职责混杂的信号，不是强制截断规则。

超过警告线时，必须说明：当前文件为何暂时保留、下一次拆分的区块是什么、是否存在运行时或业务风险。新页面不得以数千行单文件作为起点。

## 7. 迁移完成条件

页面只有在以下内容都完成后才能标记为完成：

- 入口结构清晰，页面级状态和副作用边界明确；
- 稳定复用组件已按目录分层，基础 UI 没有业务反向依赖；
- props、回调、API 参数和导入导出经逐项核对；
- 没有新增 `ReferenceError`、未定义回调、失效导入或运行时解析错误；
- `npm run build`、`npm run check:architecture` 和相关定向检查通过；
- 关键用户流程、视觉表现和接口行为保持不变。
