# 画布音频连线

更新日期：2026-10-08。状态：左侧端口连线修复、音频占位修复、先连线后输入及音频端编辑保护已由用户手动验收通过；音频生成流程及后端联调仍待验收。

- 音频只接受文本和音频上游，左右端口入口沿用统一校验。
- 左侧拖到已有卡片时优先添加上游，校验不通过则尝试反向输出。因此文本左侧拖到音频也会建立“文本 → 音频”并追加正文；两向均不合法则不连接。空白处松手仍添加上游。
- 文本建立连线时以换行分隔追加正文，不覆盖已有输入；断线不删除已输入文字，重新连接再次追加。
- 空文本允许建立关系；音频端未独立编辑时，后续上游正文按连线顺序同步，仅更新对应来源部分，保留连接前的台词。上游清空会清空对应来源部分。
- 音频端修改台词、清空台词或添加情绪/停顿等改变请求正文的标签后，停止自动覆盖该音频台词；仅选择音色或调整声音参数不停止同步。断线或删除来源保留最后一次导入内容，重连仍追加。
- 占位提示根据实际配音正文显示，预填有内容时隐藏，清空后恢复，不依赖编辑器在展开过程中的可见文本读数。
- 只读取直连上游音频，不读取下游及更上游。文本已进入输入框，不在发送时重复拼接。
- 已有音频二次创作时新增结果节点，请求发出前建立素材连线并显示加载动画，原节点内容不变。
- 失败保留空结果及连线，只显示消息提示；删除结果节点取消对应任务，不删除来源节点。
- 音频任务复用五任务并发登记；发送后关闭来源输入框，不自动展开结果输入框。
- 画布音频参考通过现有配音接口的 attachments 全量发送，同时保留首个 reference_audio_url；实际模型对多参考素材的消费仍需后端联调确认。
- 本地临时音频先上传，不向后端发送浏览器临时地址。其他页面请求行为不变。

实现入口：CanvasTextAudio、CanvasAudioGeneration、UseCanvasAudioGeneration，页面仅接线。
