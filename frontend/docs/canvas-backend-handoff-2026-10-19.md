## 一、不可变更的产品边界

- 独立项目包含多张画布；项目和画布是两个资源，项目名与画布名分离。
- 不接受“顶层画布及子画布组成的树算一个项目”作为替代；`project_id` 字段本身不证明项目生命周期已经满足需求。
- 不使用本地持久化、临时媒体地址或旧生成接口伪造正式保存恢复闭环。
- 有完整契约的独立能力可以先接入；依赖缺口的能力继续搁置。

## 四、最小验收样例

1. 创建独立项目并返回首张画布；第二张画布创建、排序、改名，项目名不变。
2. 含四类节点、连线、组、堆叠、视口及永久资产引用的完整保存与重读响应。
3. 两个客户端并发保存、409、网络超时后确认与重试的请求响应序列。
4. 图/视频/音频任务从保存、创建、刷新恢复到多结果回填、重复回填的序列；文本和编辑任务另给明确契约。
5. 资产缺失、无权限、回收站、分享关闭、导入超时后的恢复样例。

请逐项回复“已实现并附样例 / 待开发并给计划 / 需要讨论并说明原因”。收到材料后前端逐项恢复，不等待所有独立能力一起完成，也不放宽产品边界。

| 移动与引用 | 文件夹及所有条目仅允许同集合移动，后端拒绝跨集合；跨集合只添加素材引用，禁止暗中移动或复制 |
| 独立复制 | 新 copies 操作复制目录及全部素材，包括引用转独立原生资产；不复制项目。直接执行、不弹命名窗，服务端按源版本名称追加“-副本”，允许重名、不追加序号，返回新编号及名称。任一素材不可用或无复制权限则整次失败，无可见残缺副本，需失败清理及幂等查询 |
| 集合打包 | 新 downloads/preview 与 downloads 操作递归获取实际文件；遗漏先提示，用户确认才允许部分包，结果提供实际遗漏清单，不冒充完整包 |
| 全选 | 新 selections 快照覆盖当前目录所有直接条目，包括未加载项；删除递归处理所选目录。快照及删除预检限制范围变化，不用当前页编号替代全选 |
| 异步任务 | 明确复制、下载和删除操作状态、权限、幂等及恢复查询；复制返回新集合编号，打包返回受控链接、过期时间及包含/遗漏结果 |

不新增“一键清空资产”操作；右侧保留批量全选与删除。默认分类可删除改名；无法分类或分类被删时素材回落集合根目录，不补建分类。普通子目录打包尚未确认，本轮仅增加集合级打包。
