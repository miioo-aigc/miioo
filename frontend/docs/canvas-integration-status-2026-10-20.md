# 画布接口对接进度

> 更新：2026-10-21。依据当前代码及《画布功能-后端契约三项补齐交付说明-2026-10-20.md》。
> 接受交接文档明确字段作为接线依据，不再因本地 OpenAPI 未同步全面阻塞。契约交付、前端接线、部署与真实验收分别记录。

## 不变的边界

- 独立项目包含多画布，项目名称和画布名称分离。不选择、不默认绑定视觉风格。
- 不用旧生成或模拟成功冒充正式闭环，不在请求失败后降级模拟。
- 分享任何保存状态可复制，不触发保存，打开本站 /share/canvas/:token 的服务端已保存版本。

## 已接线，待真实验收

| 能力 | 当前实现及边界 |
| --- | --- |
| 正式项目入口 | 首页及画布菜单新建调用 POST /api/projects，传 project_type=canvas、create_first_canvas=true、first_canvas_title=画布1，不传风格。按 first_canvas_id 进入画布；缺编号或响应风格非空显式报错，不补造画布。 |
| 项目列表与打开 | 项目裸数组按 limit=200、offset 读完，再筛选 project_type=canvas；打开时按 project_id 查询 active 画布，校验归属并导航实际画布编号。无画布报错，不自动创建。工作流列表排除画布项目。 |
| 项目名称 | 按画布 project_id 读取项目详情；左上角改名 PATCH 项目，成功才更新。与画布 title 独立。项目复制、删除本轮未接。 |
| 请求隔离 | 连续点击只提交一次；离页、切换画布、会话失效后忽略迟到响应。创建无幂等契约，不自动重试；结果不明先刷新列表核对。 |
| 文档保存恢复 | schemaVersion/records/businessBindings 映射正文、参数、组合、堆叠、绑定、视口；移除运行态和临时地址；读取失败不覆盖原文档。 |
| 保存幂等 | client_save_id、会话内串行及原请求重放；409 保留未确认内容。不承诺刷新或跨标签后找回未确认请求。 |
| 永久资产 | 上传传正式 project_id，校验永久 asset_id；恢复按200条分批解析 ready/trashed/forbidden/missing。真实上传保存重开待验收。 |
| 多画布 | 已有同项目列表、新增、切换、改名、副本、归档；切换前保存，失败保留当前画布，至少保留一张。 |
| 分享 | 复制链接及本站公开只读页已有接线；模拟编号不能开启正式分享；部署和跨域待验收。 |
