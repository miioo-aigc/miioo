# 画布节点提示词草稿保留修复

日期：2026-11-06。状态：Suzy 手动验收通过。

## 使用行为

文本、图片、视频和音频节点下方输入框中的提示词属于节点草稿。关闭输入框只隐藏编辑界面，再次打开可继续编辑；提示词随画布自动保存，保存成功后刷新页面或离开再进入仍可恢复。用户主动清空时保存为空，不恢复旧草稿。文本节点正文与下方提示词仍是独立字段。

## 实现与原因

恢复或导入的媒体节点此前未统一绑定提示词写回回调，编辑内容可能只留在临时编辑器中。CanvasPage 现在在展示节点时对所有类型注入 onPromptChange，将 prompt 与 promptSnapshot 写回节点数据，不再仅依赖新建入口绑定或文本类型分支。

CanvasCreationPanel 向音频面板透传 promptSnapshot；CanvasAudioCreationPanel 恢复时优先使用持久化快照，文本或格式变化时同时写回文本与快照。图片、视频沿用原有快照编辑器，文本沿用受控输入及输入法同步逻辑。CanvasDocument 序列化与 UseCanvasAutosave 自动保存继续承担持久化，不新增后端接口或独立缓存。

保存仍遵循现有画布规则：停止编辑后约1秒自动保存；未完成上传或生成、保存失败等情况下不能视为已经持久化。页面原有未保存离开保护继续生效。
