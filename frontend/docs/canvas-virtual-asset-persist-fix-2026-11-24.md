# 画布虚拟认证素材保存修复

日期：2026-11-24。依据当日前后端交接文档，用户已确认后端接口上线。

## 实现

- 认证素材选择器保留 liveMaterialAssetId，画布导入清空普通资产身份。
- 文档保存、恢复独立身份，自动保存及离开检查认可该身份；非法编号仍由序列化拒绝。
- 解析请求按普通与认证素材分开发送，认证素材每批180项，普通素材沿用每批200项；缓存隔离，支持同编号。
- 认证素材预览使用 preview_url，原片使用 original_url，海报使用 poster_url；不可用及请求失败清除旧地址，保留节点与身份，并在加载时提示。
- 普通资产失效清理不删除虚拟身份。复制、导入撤销重做保留独立身份。
- 当前节点结果历史协议只接受普通资产，因此认证素材不写入普通结果历史；导入认证素材替换现有结果时清除该节点的普通结果历史。后续生成、上传或编辑从新结果开始记录。此处未扩展后端结果协议；普通历史节点的结果替换仍遵守既有不进入普通撤销的策略。

## 验证

11个定向测试文件共95项通过，覆盖身份往返、同编号隔离、不可用和请求失败、非法编号、替换、复制及导入撤销重做。接口测试补齐既有错误处理函数的注入。构建、架构检查通过；全量代码检查被本次未修改的 Home.jsx 第291行状态变量声明顺序、第829行副作用同步更新状态两处错误阻塞；构建保留体积提示，架构保留既有规模提醒。

未自动打开浏览器；真实接口访问、媒体播放和视觉效果由用户手动验证。

## 手动验证

1. 从资产库虚拟认证分别导入一张图片和一个视频，等待保存完成。
2. 刷新，确认图片显示、视频可播放及封面正确。
3. 复制节点，撤销和重做导入，切换画布再返回，确认素材恢复。
4. 若素材不可用，确认节点保留并出现提示，重新导入可用素材。

已经保存成空身份的旧节点需要重新从资产库导入，不能根据旧地址猜测归属。
