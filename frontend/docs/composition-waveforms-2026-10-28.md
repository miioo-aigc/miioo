# 剪辑真实波形接入

## 2026-10-29 波形可读性优化（待手动验收）

- 将音频高度由线性改为所有素材共用的连续对数映射：h = log(1 + 1000a) / log(2001)，a为源峰值乘工程音量，最大显示幅度2。不改变实际音量、缓存、保存或视频原声的小波形。
- 幅度0.1由波形区域5%高度提升到约61%，0.25提升到约73%；接近零的底噪仍低，零和静音保持零。目标是常见对白起伏接近卡片中部，不承诺所有素材固定半高，不按素材或可见区间自动归一化。
- 蓝黄红仍先按原始幅度的−6/0分贝边界截取，再统一映射高度；不会因视觉放大提前变色。保留素材强弱差异和滑块升降反馈。本条替代下方已验收版本的线性显示标尺，顶部着色规则延续。
- 9项波形/API回归、定向静态、构建和架构检查通过；全库静态仍有首页两项既有错误及11条警告。未打开浏览器，待用户手验对白可读性、静音、音量联动和顶部黄红分层。

## 2026-10-29 音量联动与峰值告警（用户验收通过）

- 扩展已有 WaveformDisplay 与 CompositionWaveform；TimelineBar 仅为音频波形传入所在轨道设置，不新增页面状态、副作用或请求。片段 volume 与轨道 volume 相乘，静音/隐藏归零；不受播放器监听音量影响。复用现有蓝色及 yellow-300、red-300 色值。
- 按用户参考图修正为高度分层：同一峰值底部至 −6 分贝为蓝色，超过 −6 分贝至 0 分贝为黄色，超过 0 分贝的顶部为红色；不再整根变色。恰好在边界时超出面积为零，不强行制造色带。音频使用固定2倍满刻度高度标尺，保留0分贝以上的红色空间，不按素材动态归一化；视频原声维持原标尺。裁剪、倍速和撤销继续消费原有片段数据，素材峰值缓存不修改。
- −6 分贝是用户确认的产品预警阈值，不是行业强制标准。参考 https://tech.ebu.ch/docs/r/r128.pdf，真实峰值与节目响度是独立测量；当前功能不是多轨混音、真实峰值或成片响度检测。接口只声明“归一化峰值（0~1）”，交接资料未给出算法，仍需后端确认是否保留相对满刻度的幅度；当前颜色为按现有峰值估算的风险提示，不宣称校准检测。
- 9 项波形/API回归及定向静态检查通过，构建、架构检查通过（保留体积与文件规模提醒）。全库静态检查仍有 Home.jsx:277、808 两项既有错误及11条警告。未自动打开浏览器；Suzy 于2026-10-29确认本轮音量联动与顶部高度分层着色验收通过。该验收不替代后端幅度标尺核实。
- 组件归属检查复用了既有业务组件；仓库缺失规则所引用的 feature-development.md，已按项目入口规定完成资产清单和设计系统检索。

依据用户提供的152-frontend-waveform-handoff.md及本地OpenAPI接入，未部署后端或发布前端。

- AssetWaveforms API封装鉴权GET波形与POST ensure-media-derivatives；严格验证ready峰值及源时长，拒绝畸形数据，不用假波形兜底。
- TimelineBar复用WaveformDisplay展示音频整卡和视频底部波形。源区间为offset至offset+duration×speed；保留桶边界，静音不抬高振幅。
- UseCompositionWaveforms绑定项目、工程和认证会话，监听素材集合变化，涵盖加载、添加、分离音轨、撤销和删除。卸载取消请求/定时器；迟到结果丢弃。
- 与交接参考实现不同，缓存保留在独立Hook而非工程Store，避免扩大已有Store职责；不写segment、dirty、撤销栈及保存请求。
- 同素材去重，最多4个并发请求，pending每2秒轮询、最长5分钟。失败、源缺失及超时可手动重试，先ensure再读；终态不自动无限重试。
- 首次读取旧素材可能等待后台派生；v1固定96桶，长素材短片段精度有限。兼容v2可变峰值数，不在浏览器解码。

## 验收

不同素材显示不同波形；静音区不生成虚假振幅；裁剪、分割、倍速后对应源区间；重复素材只读取一份；失败重试不触发片段拖动/定位；离开页面停止请求；保存、撤销、导出协议不包含波形。

本地验证覆盖峰值校验、API方法/取消信号、源区间映射、两种精度、请求去重、并发限制、轮询终止、失败重试、卸载与认证代际隔离。真实服务与浏览器显示由用户手动验收。
