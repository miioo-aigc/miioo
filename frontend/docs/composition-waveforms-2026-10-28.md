# 剪辑真实波形接入

依据用户提供的152-frontend-waveform-handoff.md及本地OpenAPI接入，未部署后端或发布前端。

- AssetWaveforms API封装鉴权GET波形与POST ensure-media-derivatives；严格验证ready峰值及源时长，拒绝畸形数据，不用假波形兜底。
- TimelineBar复用WaveformDisplay展示音频整卡和视频底部波形。源区间为offset至offset+duration×speed；保留桶边界，静音不抬高振幅。
- UseCompositionWaveforms绑定项目、工程和认证会话，监听素材集合变化，涵盖加载、添加、分离音轨、撤销和删除。卸载取消请求/定时器；迟到结果丢弃。
- 与交接参考实现不同，缓存保留在独立Hook而非工程Store，避免扩大已有Store职责；不写segment、dirty、撤销栈及保存请求。
- 同素材去重，最多4个并发请求，pending每2秒轮询、最长5分钟。失败、源缺失及超时可手动重试，先ensure再读；终态不自动无限重试。
- 首次读取旧素材可能等待后台派生；v1固定96桶，长素材短片段精度有限。兼容v2可变峰值数，不在浏览器解码。

## 验收

不同素材显示不同波形；静音区不生成虚假振幅；裁剪、分割、倍速后对应源区间；重复素材只读取一份；失败重试不触发片段拖动/定位；离开页面停止请求；保存、撤销、导出协议不包含波形。

本地验证覆盖峰值校验、API方法/取消信号、源区间映射、两种精度、请求去重、并发限制、轮询终止、失败重试、卸载与认证代际隔离。真实服务与浏览器显示由用户手动验收。
