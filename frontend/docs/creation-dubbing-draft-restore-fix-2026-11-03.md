# 高级配音刷新恢复修复

日期：2026-11-03。状态：用户手动验收通过。

## 问题与确定规则

刷新后高级模式开关恢复为关闭，但草稿的富文本仍带情绪标签，造成普通模式显示高级内容。原因是开关只存在于组件状态，草稿保存了输入框内容却没有保存模式。

确定规则：刷新恢复上次模式、台词和情绪设置；只有用户主动关闭高级模式时，才按现有确认流程清理高级内容。

## 有效实现

- CreationInputCard.jsx：配音草稿新增 dubbingAdvancedEnabled、dubbingEffects，与原有 promptHTML 一起保存；恢复时同步回写开关与效果。
- CreationDraftStorage.js：resolveDubbingDraftState 优先采用明确保存的开关值；旧草稿未记录模式时，根据情绪或停顿/语气词标签推断高级模式。普通文本不自动开启；明确关闭优先于标签推断。
- 恢复写入保护：pendingDubbingRestoreRef 等待模式及效果完成状态回写后才允许保存，避免初始普通模式覆盖已恢复的高级草稿。
- 主动退出沿用原确认与清理流程；草稿清空事件同时重置模式、效果和待恢复标记。
