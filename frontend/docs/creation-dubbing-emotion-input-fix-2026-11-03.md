# 高级配音情绪句末输入修复

日期：2026-11-03。状态：用户手动验收通过。

## 问题与预期

创作页面 → 配音 → 高级模式，设置情绪后，在句末用中文输入法直接输入汉字，新内容仍继承情绪。英文直接输入、先输入空格再输入文字、句中输入均正常。预期：句末新增内容包括空格不继承情绪，无须先输入空格；句中插入保留情绪。

## 最终有效修复

核心代码：src/components/creation/CreationPromptEditor.jsx。

1. onCompositionStart：仅在高级配音、编辑器可用、选区已折叠且光标位于情绪正文真实末尾时触发。记录原正文长度，在情绪标签后插入空文本节点并将光标移到标签外，交给输入法正常组字。
2. onCompositionEnd：若浏览器仍使用缓存的旧落点，导致情绪正文比组字前变长，则按原正文长度定位边界，将末尾新增文字移到情绪标签外。使用实际正文内容，不根据事件数据重复插入候选词。
3. 修正后将光标移到新增普通文字末尾，派发输入事件以同步内容与草稿，并清理未使用的空文本节点。
4. 句中光标后仍有正文，不触发上述隔离，保留原情绪。英文和空格沿用既有输入处理。

src/components/creation/useCreationPromptInteraction.js 保留普通输入事件兼容与情绪边界处理。解决中文句末问题的关键是在组合输入开始和结束阶段处理边界，不能仅依赖组合完成后的 onBeforeInput。之前未通过验收的边界判断、事件字段调整不单独列为成功修复。
