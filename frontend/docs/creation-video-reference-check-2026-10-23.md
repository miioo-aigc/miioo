# 创作视频重新编辑参考图排查

日期：2026-10-23。范围：重新编辑回填、参考素材上传、视频生成提交前检查。

## 结论与边界

已确认原流程存在预览图误作原图、回填丢失资产编号、详情恢复期间可发送旧输入、上传失败后丢素材继续生成的路径。它们能够造成错误请求，但尚未证明是用户反馈“参考不上”的实际根因。浏览器缓存状态不能直接代表上游能否读取图片；本次客户端检查通过，也不能保证上游访问、模型参考效果或历史链接长期有效。

## 已修复

- 详情恢复期间禁止发送及重复重新编辑，详情失败提示重试。
- 回填分离原图与预览，保留资产编号，不用预览补原图；缺失首尾帧显式清空，避免沿用上一条记录。
- 视频参考素材及首尾帧上传失败、响应缺失地址时停止生成。
- 提交前等待原图加载，单张最多等待20秒，加载失败或取消时停止；拒绝临时地址、派生预览、下载入口和不支持的AVIF地址。只有资产编号或服务商素材身份时保留后端解析路径。
- 视频生成接口非成功响应直接作为错误反馈。

保留原有职责边界：结果组件编排详情恢复及回填；适配工具组装数据；独立请求工具检查图片；现有请求入口集中上传及生成副作用。本次未拆分整个请求文件。

## 验证

参考图就绪、素材身份和图片参考相关19项测试通过；构建、架构检查、修改文件定向代码检查及差异空白检查通过。全仓代码检查仍有首页第271行与第802行原有错误，以及画布节点和分镜提示词组件共3条警告。未打开浏览器或调用真实生成服务。

## 手动验收

1. 视频重新编辑后立即发送：详情恢复时不可发送，原图仍加载时等待；失败时明确提示，不提交生成。
2. 图片显示后发送：确认参考素材数量、顺序与首尾帧对应正确，并检查生成结果。
3. 弱网或失效图片：检查失败提示与输入恢复；上传失败时不产生缺图任务。
4. 连续重新编辑不同记录：无首尾帧的记录应清空上一条首尾帧。

若正常显示后仍参考不上，需进一步对照失败任务的素材来源、资产绑定、实际原图地址和后端转发给上游的参数。避免在记录中写入令牌或带私密签名的完整地址。
