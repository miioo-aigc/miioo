# 剪辑草稿分集隔离接口交接

日期：2026-10-23。前端已接线，后端待实现或确认支持后联调。

## 根因

现有 OpenAPI 及 2026-10-13 接口文档中，composition 仅归属于项目。分集只参与初始分镜视频选择，未写入工程归属。当前仓库无后端源码，本次未部署或修改后端。

## 后端要求

1. 数据库增加 episode_id 字段及项目/分集索引。新建必填，校验分集存在、属于当前项目且用户有权限。历史测试记录可保留 NULL，不做迁移、认领或删除。
2. POST `/api/projects/{project_id}/compositions` 接收并持久化 episode_id。创建响应返回真实保存值，不能静默忽略字段。复制复用此接口并传原草稿分集。
3. GET `/api/projects/{project_id}/compositions?episode_id={episode_id}` 同时按项目和分集过滤，不返回其他集或 NULL 记录；无结果返回空数组。保留不传分集的项目级查询，供导出任务恢复使用。
4. 列表、创建、更新、渲染的 CompositionResponse 均包含 episode_id。普通 PATCH 不改变归属，仍需校验权限和项目范围。
5. 同步 OpenAPI 和接口文档。

## 前端处理

- 新建、自动新建、复制传 episode_id；未选分集不创建。列表做二次过滤，避免服务端漏过滤时串集。
- 创建响应归属缺失或不一致时报错，不进入编辑器。旧后端可能已创建无归属记录，报错不代表服务端回滚，联调前避免反复创建。
- URL 保留 episode_id；指定草稿不属于当前集或失效时不打开其他草稿。编辑器素材分集筛选不改变工程归属。
- 既有测试草稿不迁移、不删除、不在分集列表显示。

## 验收

- 第一集创建 A，第二集创建 B，第三集为空，各集互不显示其他集草稿。
- 第一集已有 A 时，第二集在线剪辑仍应自动创建并提示新建剪辑成功；已有草稿的分集进入列表。
- 复制继承分集，保存、刷新、返回不丢归属。
- URL 的草稿与分集不匹配时显示错误，不回退第一条草稿。
- 查询失败不创建；创建失败或归属缺失不提示成功；非法分集和跨项目分集由服务端拒绝。
