# 剪辑后端接口接入记录

契约来源：后端《剪辑模块-API接口文档-2026-10-13.md》，本轮以该交接文档为新增字段依据。本地旧 OpenAPI 尚未替换，待后端提供机器可读版本，不伪造已同步状态。

## 已接入

- Composition 归一化增加 libraryAssetIds、trackSettings；POST/PATCH 映射 library_asset_ids、track_settings，保留省略/null/清空三态。轨道设置使用对象，清空为 {}，不传文档中与 dict 类型矛盾的 []。
- video 写入/恢复 has_audio，audio 写入/恢复 volume（0–2，两位小数），旧数据默认 true / 1。字幕沿用 text/style，无 clip_id。
- 片段音量提交、轨道静音/隐藏/吸附修改触发 dirtyRev，走现有自动保存与手动保存。
- 素材上传/选择后保存有序引用，读取按顺序恢复；补取 timeline 与 library_asset_ids 的并集。不可用引用保留 ID、显示警告，避免下一次保存静默删掉引用。
- 删除素材同步移除当前工程 library 引用与关联片段，不删除共享资产。复制草稿透传素材列表和轨道设置。
- 导出保存失败、提交失败保留后端中文错误。未提供百分比时不再固定显示 0%；导出弹窗时长统一包含全部轨道。

## 2026-10-15 创作音频草稿引用（当前规则）

- 产品明确不创建项目副本：CompositionAssetImport 只读取原资产，校验类型及删除状态；草稿 library_asset_ids / timeline.clip_id 直接引用原 ID，播放使用原 file_url。不 POST/PATCH 资产，不改变原素材可见范围。
- 后端待补：草稿级素材引用关系及授权校验，允许用户有权限访问的创作音频被该草稿引用；保存、读取、渲染需使用同一引用解析规则，不应仅因 project_id 不同拒绝，也不能简单移除权限校验或信任任意 URL。
- 从草稿移除引用不删除原资产；其他草稿不受影响。原资产回收/失效继续给出明确错误。前一方案已创建的副本不自动清理。
- 前端行为有自动化覆盖；后端未改之前，跨项目音频保存仍可能报不可用。实际媒体 CORS、解码与发声、保存回读、导出仍需联调。

## 后端限制与未闭环事项

- 保存显式 timeline=[] 或只有音频/字幕时后端返回 400。前端保留失败与 dirty，不省略时间线制造假成功。删空、仅字幕草稿、空草稿仅上传素材等工作流仍需后端分离保存与渲染校验。新建继续省略 timeline。
- 资源只允许同用户同项目且未回收；跨项目选择资源可能被拒，保留后端错误，不绕过权限。
- 主轨 mainTracks 无协议字段，继续会话级。library_asset_ids 为手动素材列表，动态定稿素材的排除状态无协议，移除后重新加载仍可能出现。
- 文档仅 render 响应携带 task_id，刷新后任务恢复未闭环。2026-10-15 已分离弹窗开关和任务观察，当前会话支持返回列表及切换草稿后持续显示多个导出任务。
- 多视频原声全量混音与当前单活跃视频预览存在差异；前后端共享字体尚未交付到本仓库。不可宣称预览与成片完全一致。
- 尚未执行真实服务器保存回读、跨设备恢复、媒体导出及浏览器视觉验收。自动化请求测试使用受控响应，不能替代联调。
