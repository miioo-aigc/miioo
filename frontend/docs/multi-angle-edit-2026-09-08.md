# 多机位编辑实现记录

日期：2026-09-08

## 已接入

- 共享 ImageDetailModal 的多机位入口，标题为多机位编辑。
- ImageEditHeader、ImageEditFooter 由裁剪与多机位共用；多机位直接使用与图片详情、裁剪相同的useModalSize，基准尺寸1200px × 800px并使用相同缩放，不再额外限制视口尺寸或切换移动端布局。
- 公共重置按钮恢复设计稿双向重置图标与白色80%文字，图标14px、文字13px/16px、按钮高40px、水平内距12px、间距4px；局部样式覆盖链接按钮默认品牌色，不修改其他链接按钮。
- Three.js 网格球、立体摄像机、连续拖拽、四向5度按钮及后方图片透明处理。
- 水平0至360度环绕，垂直-30至60度截断；九宫格预设及原生键盘可操作滑杆。
- 使用原图引用及动态中文提示词调用已有图片生成API，不发送虚构的角度接口字段。
- 图片创作结果列表复用现有生成占位、任务快照及结果写回。
- 资产共享图片详情通过来源键隔离派生结果；原图不变，新占位与结果插入原卡片相邻位置。

## 边界与未完成验收

- 主体多图、分镜使用独立详情组件，尚未接入多机位，不能描述为所有图片入口均已完成。
- 资产来源结果在本次应用运行期间跨组件卸载保留；刷新后没有来源列表恢复快照，服务端仍按现有创作API保存结果。项目特有的主体/分镜绑定没有新增接口支持。
- 资产派生结果失败时保留失败卡；图片创作链路沿用现有失败移除占位行为。
- 三维模型表达目标机位，不是真实生成预览，提示词不能保证模型精确执行角度。
- 浏览器测试依赖安装审批两次超时，未完成桌面/移动端截图、画布像素和真实页面提交测试，未发起付费生成。
- 参数单测3项通过，构建通过。全量lint被AssetsCards.jsx既有storyboardMediaFit未使用阻塞；架构检查被seedanceUploadValidation.js既有文件命名阻塞。

## 组件归属

多机位UI、三维预览和来源生成动作在components/image-edit；角度规则在utils/MultiAngle.js；来源结果状态在stores/multiAngleStore.js。基础UI不引用业务API。设计稿数字间距已转换为具体CSS像素值。
