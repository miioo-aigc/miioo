# 扩图弹窗进度快照

> 更新时间：2026-09-17  
> 范围：仅前端展示与提交参数组织，不接后端展示链路。  
> 主要文件：`src/components/image-edit/OutpaintModal.jsx`、`src/components/image-edit/Outpaint.css`

## 需求基线

1. 原图固定在展示区内，默认按可视区域面积的 10% 展示；滚轮只缩放图片的视觉尺寸，不改变真实像素。
2. 编辑框默认比原图大 1.5 倍，居中扩图；拖动边缘或控制杆时锁定比例扩大。
3. 编辑框不允许小于当前显示中的图片；提交前只计算并传递扩图比例，不传真实扩展像素。
4. 扩图约束在编辑阶段生效：四方向扩图比例均为 `[0, 2]`，且总面积不超过原图的 3 倍。
5. 拖拽编辑框不改变图片视觉尺寸；滚轮瞬间以当前编辑框为上限，扩大编辑框后滚轮可继续放大到新框边界。
6. 比例选项、提示词输入框、控制杆样式分别复用裁剪弹窗和局部重绘弹窗的既有样式；不保留旧的 `outpaint-toolbar`。
7. 扩图区域的像素格由 CSS 绘制，不使用贴图。

## 当前完成

- 已实现独立扩图弹窗，默认选择“原比例”，初始编辑框为原图 1.5 倍。
- 已实现编辑框居中模型、锁定比例拖拽和八方向控制杆操作。
- 已实现最小边界限制：编辑框不小于原图，也不小于当前显示中的图片。
- 已在拖拽阶段限制单边扩图比例 `[0, 2]`，并限制总面积不超过原图 3 倍。
- 已实现滚轮缩放后的动态上限：放大图片后允许更大的编辑框；真实像素不变，最终仍换算回原图比例提交。
- 已修正拖拽联动：扩大编辑框时图片保持当前视觉尺寸，不会跟随编辑框放大。
- 已实现滚轮缩小后的自动收缩：旧编辑框超过新上限时，锁定比例收缩到新上限，并保持不小于原图和当前显示图片。
- 已移除旧的“扩图区域大小 / 锁定比例”工具条。
- 已实现 CSS 像素格，未使用贴图。
- 已接入局部重绘弹窗的提示词输入框样式。
- 比例选项已同步裁剪弹窗的默认、悬停、激活颜色状态。
- 扩图与裁剪弹窗的四角控制杆锚点已统一为角点中心对齐。
- 提交参数已组织为 `up_expansion_ratio`、`down_expansion_ratio`、`left_expansion_ratio`、`right_expansion_ratio`。
