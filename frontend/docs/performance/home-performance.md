# 首页性能优化记录与验收

2026-11-02，范围为当前项目应用首页。

## 核查事实

首页单个视频顺序轮播八段外部视频，未找到反馈描述的大型内嵌宣传图片或滚动视差。第一段视频为H.264、1280×720、24帧。这不构成崩溃复现，也无法证明浏览器发生内存耗尽。

## 已实施

- 页面隐藏和离开时暂停背景视频，重新可见恢复；卸载显式移除媒体源并释放资源。
- 视频显式使用metadata预加载；自动播放仍然会读取视频，不代表下载或解码内存上限。
- 轮播结束回调不在隐藏页面主动播放。
- 标语取消永久逐字合成提示，入场结束及卸载清理动画实例；减少动态效果时直接显示文字。

## 验证状态

两个组件定向静态检查、生产构建、架构检查及差异空白检查通过。未打开浏览器，未测量峰值内存、帧率及实际崩溃。子代理调用接口持续返回缺少参数错误，未能建立执行和独立审核代理，不应宣称独立审核通过。

## 用户手动回测

1. 同一设备浏览器冷启动优化前后各三次，记录任务管理器内存、资源请求量和可交互时间。
2. 首页轮播十分钟，检查内存是否持续增长。切后台一分钟再回来，确认暂停与恢复。
3. 首页和资产库往返十次，确认离开首页后无后台视频播放。
4. 验证文字动画、八段视频轮播、登录与开始创作；开启减少动态效果后确认文字正常显示。
5. 若仍崩溃，记录完整网址、部署版本、浏览器和设备信息、崩溃时间并采集性能轨迹。

## 待完成

独立代理审核、运行时内存和帧率对比、其余视频参数与资源预算核查。未经测量不能承诺已修复用户崩溃。
