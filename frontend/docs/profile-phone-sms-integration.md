# 个人信息短信接入记录

更新日期：2026-11-12。依据后端 2026-11-11 短信交接文档。

## 已实现

- 首页与画布共用 src/components/ProfileModal.jsx，无独立画布副本需要同步。
- 换绑采用单步新号码验证，调用 rebind/send-code 和 rebind；禁止脱敏号发码。
- 注销发码调用 phone/unbind/send-code，不发送号码；DELETE /api/users/me 携带 code。未绑定手机号时不显示验证码字段、不发码。
- CodeInput 仅通过 onSend 发码；API 校验 message、expires_in 后才启动 60 秒重发倒计时（有效期不等于重发间隔）。
- 发码与提交期间锁定输入和按钮，沿用 useProfileOperation 的 ref 防重与账号、取消、卸载隔离。
- 短信错误仅展示白名单业务文案；未知错误使用固定提示。移除不存在的 phone/unbind 封装。
- 保留既有弹窗布局及资料自动保存、微信绑定边界。本次限定短信合同修复，未重构整个历史大组件；后续可单独抽离手机与微信弹窗。

## 接口版本与发布

仓库 openapi.json 尚未包含注销发码和注销 code 请求体；本次按较新的交接文档实现。上线前应由后端更新正式 OpenAPI 并确认目标环境支持新合同。

后端与前端在同一发布窗口切换；已绑定账号的旧版注销请求在后端升级后会失败。构建使用 Vite 默认清空本地 dist 的行为。
线上应使用干净的完整 dist 发布目录切换，不向旧 assets 目录累加文件；同步刷新 HTML/CDN 缓存，核对入口引用的是本次构建资源。仓库没有站点发布脚本，本次未修改线上文件或执行发布。
