# 剧本往返与页面恢复

验收日期：2026-10-27。状态：用户验收通过。

## 最终交互规则

- 用户可从解构页返回对话查看历史，也可从对话回到已有解构。
- 继续对话产生候选稿，不自动采用，不清空或替换已有解构。
- 已有解构允许编辑、保存以及继续生成主体，不展示旧结果提示。
- 只有用户在对话结果页确认进入剧本编排，才使用当前稿重新编排。
- 新稿不满意时，用户仍可返回使用原有解构结果。

## 页面位置恢复

- 按项目保存当前浏览器内最后主动进入的页面，对话和解构分别记录。
- 在对话页离开项目，再次进入或刷新恢复对话页。
- 在解构页离开项目，再次进入或刷新恢复解构页。
- 明确停留记录优先；无记录时，有解构结果优先显示解构页，否则显示对话页。
- 没有可恢复的解构时回退对话；读取恢复不覆盖用户保存的停留偏好。
- 使用浏览器本地存储，不承诺跨设备、跨浏览器同步；存储不可用不阻断切页。

- ScriptPage 编排工作区恢复、服务端解锁、已有结构保留与页面切换。首次返回对话仍保留重复点击互斥和项目/账号迟到响应隔离；后续往返不重复覆盖对话内容。
- ScriptMessageArea 提供返回已有编排与确认重新编排的两个入口。
