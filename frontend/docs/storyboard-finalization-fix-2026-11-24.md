# 分镜候选唯一性修复

规则：同一分镜的图片和视频合计最多一个定稿；允许取消为零。

原因：候选与旧分镜素材合并后保留各自定稿标记；读取时也会从旧素材地址恢复已取消的定稿。修复统一读取、合并展示和保存后的标记，两个字段别名同步清除。候选编号优先，防止同地址多个候选勾选。保存期间忽略同一分镜重复点击，过期读取响应不覆盖新状态；详情保存失败时保持原状态。

后端仍按现有接口契约负责事务内互斥；本次没有修改后端或执行历史数据库清理。历史多标记在展示时收敛为第一个有效候选。2026-11-24，用户确认本轮手动验收通过。

验证：新增五项定稿回归测试，以及已有十四项候选合并与媒体身份测试通过；定向静态检查、构建和架构检查通过。未自动打开浏览器。全量静态检查仍有 Home.jsx 第 291、829 行的两处既有错误及 11 条警告；本次涉及文件定向检查通过。构建有包体积提醒，架构检查有文件规模提醒，均无阻断。
