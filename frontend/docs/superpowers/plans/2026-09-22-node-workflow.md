# 节点式工作流前端开发计划

> 更新日期：2026-09-22
> 执行要求：使用 Superpowers 的子任务驱动开发或执行计划技能，逐个小阶段实施、验证并更新本表。按用户确认的范围逐阶段开发，不自动展开全部计划。

**目标：** 从零搭建能够编辑、保存、恢复并手动生成的节点工作流前端。

**架构：** React Flow 负责画布交互，业务文档与画布内部状态分离。Zustand 按职责管理文档、临时交互和运行状态；后端负责持久化、执行授权与可靠任务记录。

**技术栈：** React 19、React Flow、Zustand、Vite、项目现有设计系统。

**详细依据：** [数据与工程规划](../../node-workflow-data-planning.md)。本表追踪开发进度，详细规则以该文档为准，不复制维护第二套规则。

## 开发约束

- 全屏画布外壳已有 Paper 设计稿，按已提供设计实施；尚无设计的节点及其他界面不自行决定正式视觉，复用现有控件和 Token。
- 智能体只预留编辑入口，不允许发起扣费生成；模板、全局执行和智能体不纳入本轮开发。
- 下游下次运行使用上游最新成功成果，提交后固定输入；旧成果保留在资产库。
- 不在节点组件里自行轮询，不直接持久化 React Flow 内部对象，不复制整个创作页面。
- 不自动提交或推送；不修改与当前阶段无关的代码。
