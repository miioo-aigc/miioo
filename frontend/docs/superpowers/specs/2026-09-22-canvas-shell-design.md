# 自由画布独立页面接入方案

> 日期：2026-09-22
> 状态：项目身份策略 B 已确认；本方案待审阅，尚未实施
> 依据：[数据与工程规划](../../node-workflow-data-planning.md)、[开发计划](../plans/2026-09-22-node-workflow.md)

## 目标与设计依据

从自由画布列表点击“新建项目”，先在后端创建真实画布，再进入不含首页侧栏的全屏编辑页面。页面按 [Paper 设计稿](https://app.paper.design/file/01KQYRKV5GAPKWF7X9K33912CS/C-0/2IHH-2) 实现，不另行设计视觉。

采用独立页面入口，不继续向 Home 堆叠画布逻辑。React Flow 管理画布视口与点阵，悬浮控件采用屏幕坐标，不随画布缩放。当前阶段不实现完整节点编辑器、保存调度或生成任务。

## 项目身份与接口

- 创建：`POST /api/canvas-documents`。标题使用接口默认值“未命名画布”；传入 `client_request_id`，同一次创建遇到网络不确定性时重试复用该标识。
- 独立画布不传普通项目归属 `project_id`，不调用普通项目创建接口。后端原子创建画布及绑定的创作会话。
- 成功取得画布 `id` 后进入 `/workspace/canvas/:canvasId`。该编号不是普通项目编号，也不是创作会话编号。
- 列表：`GET /api/canvas-documents`，复用现有列表展示，通过适配映射标题等字段，不混入普通项目数据；分页需遵循接口返回的总数，不能静默只展示第一页。
- 详情：`GET /api/canvas-documents/{canvas_id}`。刷新只读取详情，不再次创建；无权限、不存在及网络失败显示明确状态，不伪装为空画布。
- 请求封装在 `src/api/`，沿用现有鉴权和错误处理。接口文档存在不等于部署环境已验证可用，真实联调另记结果。

## 页面职责

| 模块 | 职责 |
| --- | --- |
| 独立画布页面入口 | 路由身份、认证、详情加载、错误状态和区块编排 |
| 画布列表业务区块 | 画布列表请求、新建防重复点击、创建失败反馈和导航 |
| 画布顶部区块 | 左上品牌返回首页；右上复用现有用户菜单及关联动作 |
| 画布视图区块 | React Flow 容器、自适应点阵、平移缩放、小地图 |
| 中央空状态 | “双击画布，添加节点”；素材菜单和三类创作入口 |
| 悬浮工具栏与浮层 | 添加、抓手、资产库、搜索、小地图、分享入口及菜单状态 |

组件优先从现有组件清单及设计系统复用，新增稳定区块放在画布业务目录。用户菜单若与首页闭包耦合，先盘点依赖后复用，不复制整套认证逻辑。

## 本阶段交互边界

- 实现全屏路由、真实创建和回读、品牌导航、用户菜单、点阵平移缩放、抓手切换、小地图开关、菜单打开关闭。
- 双击画布与“添加节点”打开添加入口；中央“添加素材”展示文本、图片、视频选项。
- 节点创建、素材写入、节点搜索、链接授权分享、节点导出尚需后续能力。本阶段保留所需入口，未实现动作必须明确提示暂未开放，不假装添加、保存或分享成功。
- “剧本创作、图片创作、视频创作”是后续添加对应节点的入口，本阶段不跳转旧创作页面，不触发生成。
- 复制页面地址不等同于链接分享，不在没有权限协议时声称他人可访问。
- 空状态仅在确认文档为空时显示；非空文档结构不支持时明确提示，不将其当空文档覆盖保存。
- 本阶段不写回节点文档，不承诺刷新恢复编辑结果；取得真实身份只完成创建和读取链路，不代表保存闭环完成。

## 验证与交付

- 验证创建成功、连续点击、失败重试与创建响应丢失；刷新不重复创建。
- 验证画布列表与普通项目列表数据隔离、返回列表后可重新打开。
- 验证无权限或失效编号、登出、切换画布时旧请求不会覆盖新页面。
- 验证桌面与窄视口下真正全屏、顶部与底部无遮挡、点阵自适应、菜单关闭与焦点行为。
- 执行项目规定的代码检查、构建、架构检查及差异检查；分别记录浏览器验证与真实接口验证，不能以模拟通过代替真实联调。
- 阶段完成后更新开发计划、PROJECT.md、组件清单；不把本阶段标记为完整画布骨架或保存闭环完成。
