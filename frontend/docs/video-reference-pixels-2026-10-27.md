# 视频参考图像素校验

日期：2026-10-27。状态：已实现，待手动验收。

## 规则和职责

- 每张原图宽×高不得超过36,000,000；等于允许。任何图片超限或尺寸无法确认，整个生成请求停止并中文提示。
- VideoReferencePixels负责尺寸读取、20秒超时、一次重试、成功结果5分钟缓存和并发合并；失败不缓存，本地文件释放对象地址。取消当前等待不破坏共享读取。
- VideoReferenceValidation负责收集普通参考、资产编号、首尾帧、主体、多帧及认证素材并解析原图；CreationVideoReferences负责普通原图地址门禁。创作和分镜接口统一接入，画布通过apiGenerateCreation复用。
- 资产详情优先original_url/file_url，认证素材使用source_url；不以预览尺寸放行。受控下载只向本站或配置接口域携带认证，外部图片由浏览器直接读取，避免额外跨域预检。
- 本地文件在点击生成时、上传前校验，上传后仍有提交前原图校验；不承诺只读取一次。生成请求保留原素材身份。

## 验证与边界

- 22项自动化通过，覆盖上限边界、失败恢复、缓存及并发、版本变化、原图优先、认证素材、受控下载、超时与取消、失败不提交、正常提交。
- 定向静态、构建、架构及差异检查通过。全仓静态存在范围外Home两错误及CanvasNodeShell、PanelPromptInput三警告，不标记全仓通过。
- 未打开浏览器、未调用真实生成；模拟测试不能证明线上误拦截率。
- naturalWidth/Height在特殊低内存降采样环境可能受影响；应用缓存版本失效不等同绕过浏览器HTTP缓存，后端仍需保留最终校验。

## 手动验收

1. 创作、分镜、画布分别使用6000×6000图片，确认正常提交；8000×5000图片确认中文提示且无生成请求。
2. 检查普通参考、首尾帧、主体、多帧、资产库及历史重新编辑；多张中一张超限时整次停止。
3. 检查认证图片和受控原图，确认正常素材能通过，不使用缩略图尺寸。
4. 弱网、失效地址时不提交，网络恢复后重试可成功；取消等待后不继续提交。
5. 观察常见合格图片是否出现无法确认，记录素材来源及提示，以便区分实际失效与误拦截。
