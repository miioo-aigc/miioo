# 节点工作流前端更新需求（实施版）

日期：2026-11-06。对象：产品、设计、前端及后端协作人员。

本文是节点工作流改造的实施入口，合并产品交接说明及 2026-11-05 至 2026-11-06 的需求确认。本文取代此前版本中“新结果等待手动选择”“再次生成保留旧定稿”等已废弃表述。仅整理文档，未实施业务代码，未打开浏览器或验证真实生成。

## 1. 阅读约定与结论

- **已确认**：需求和产品负责人明确确认，开发必须按此实现。
- **实现约束**：落实已确认规则所需的数据一致性和技术条件；不指定具体视觉形式。
- **待确认**：视觉细节、后端字段或尚未拍板的边界。开发不得把推荐方向自动当成已确认。

核心结论：节点是稳定任务；文本、图片、视频的新结果覆盖当前输出，旧结果进入历史；图片一次生成多个结果时，在当前批次内 N 选 1，新批次成功后默认选第一张有效图片。节点身份、位置和连线不因生成结果更新而改变。

## 2. 目标、范围与非目标

### 2.1 目标

让成熟工作流可以反复执行而不被生成行为改变。节点代表任务，只有一个当前结果对外输出；候选和历史在节点内查看，不拆成画布节点，不自动运行下游。

### 2.2 本次范围

- 文本、图片、视频输入框只配置并执行当前节点。
- 取消“有结果时自动创建结果节点”的旧行为。
- 文本、单张图片、视频生成成功后自动覆盖当前结果。
- 图片批量结果收纳在当前节点，本批次默认第一张有效图片，用户可在本批次内改选。
- 新批次成功后取代上一批次的当前地位；旧结果、旧批次和选择记录保留到历史。
- 上传替换当前结果；图片、视频编辑工具的结果也回到原节点。
- 候选展开、历史查看、明确恢复历史结果、上游更新标识。
- 配置草稿、执行快照、任务身份、当前结果、候选批次、历史及依赖版本的保存恢复。
- 复制、撤销、导入导出、分组、分享与依赖锁定的兼容。
- 生成任务 ID 前后的操作锁定、下游依赖保护及删除取消任务。

### 2.3 非目标

- 不增加“关闭后恢复旧生成行为”的开关。
- 不允许把候选拆成独立节点，不允许候选单独连线。
- 不自动执行下游，不自动运行整条工作流。
- 节点历史不等于整张工作流的版本快照；整张工作流按历史运行恢复不在本次范围。
- 音频节点已有独立生成及文本同步逻辑，本次未确认调整；共享模块改动不得破坏音频回归。
- 四来源“替换”菜单和“从当前画布选择”未整体确认，不因历史讨论自动加入。
- 刷新后继续执行后台生成不属于已确认能力；是否支持需产品另行确认。

### 2.4 成功标准

用户能在同一节点反复生成或编辑，节点和连线保持不变；当前结果明确且唯一；旧结果可查、可恢复；下游能判断输入是否已更新；分享只暴露当前结果；保存重开后不丢失候选、历史或依赖状态。

## 3. 核心概念

| 概念 | 定义 | 不应混淆的内容 |
|---|---|---|
| 任务节点 | 有稳定身份和输入连接的任务载体 | 不是一次请求或一张图片的临时容器 |
| 配置草稿 | 当前正在编辑的提示词、模型和参数 | 不等于本次任务的执行快照 |
| 输入素材 | 明确连接的直接上游当前结果，或主动添加为参考的素材 | 不自动包含节点自身结果，不递归累加祖先素材 |
| 执行快照 | 一次任务实际使用的配置、输入和版本 | 任务发送后不受后续草稿和连线修改影响 |
| 候选结果 | 一次生成或替换产生的可选内容 | 不拥有画布节点身份和端口 |
| 当前结果（定稿） | 当前节点唯一对外输出的结果 | 可以更新或从历史恢复，但不表示永久锁定 |
| 候选批次 | 按一次生成或编辑任务组织的结果集合 | 不等于完整历史列表，也不等于撤销栈 |
| 结果历史 | 统一查看全部批次、旧当前结果的列表 | 不是整张画布的历史，不因浏览而切换当前结果 |
| 服务端任务 ID | 后端受理任务后返回的真实任务身份 | 不是前端本地请求编号，不能互相冒充 |
| 提交阶段 | 已发送请求，但尚未取得服务端任务 ID | 只锁当前节点及关联连线，不锁整张画布 |
| 生成阶段 | 已取得服务端任务 ID，任务仍在执行 | 可改下一次草稿；不能替换或切换当前结果 |
| 依赖锁定 | 下游提交中保护其直接上游当前输出的机制 | 不等同于上游自身生成锁定 |
| 上游更新标识 | 提示直接下游的当前结果可能已过时 | 不跨层传播，浏览历史不会清除 |
| 独立素材节点 | 承载导入素材、供其他节点引用的节点 | 与节点内上传替换当前结果不同 |
| 编辑任务 | 图片裁剪、扩图、视频编辑等显式编辑操作 | 是“自身结果不作为生成参考”的显式例外 |

同一节点可同时存在“当前结果、旧批次、历史结果、配置草稿、下一次任务快照”，不能靠覆盖同一组字段表达。

## 4. 已确认的产品规则

### 4.1 输入框与执行目标

1. 首次生成、再次生成和失败重试都执行当前节点，不因执行新增节点或连线。
2. 输入框跟随选中的生成节点，切换或取消选中不丢失已填写草稿。
3. 提示词、模型、比例、分辨率、数量、时长、模式等属于当前任务配置，实际可用参数以模型能力为准。
4. 当前节点有无结果不改变输入框作用对象。
5. 继续加工必须显式创建并连接目标节点；右侧“＋”只创建、连线、选中并展开输入框，不自动执行。
6. 图片数量大于一仍只执行当前任务，不回到旧的多节点生成流程。

### 4.2 输入与提示词

1. 自身当前结果、其他候选和历史结果都不自动成为自身生成参考。2026-11-06再次确认：文本、图片、视频统一执行；输入框参考候选、参考数量校验和实际生成请求均须排除当前节点，不仅在最终请求时过滤。明确针对原素材的裁剪、扩图、视频编辑仍属于显式编辑操作。
2. 只读取当前任务明确指定的直接输入；不因上游曾引用其他节点而递归提交祖先素材。
3. 上游作为输入时，只提供其当前结果，不提供全部候选和历史。
4. 参考区显示、数量限制、顺序、首尾帧角色和实际请求材料必须来源一致。
5. 通过连线引入的输入，移除时必须同步断开关系；主动添加的参考有独立移除入口，不得误删其独立素材节点。
6. 已连接的直接上游没有有效结果，或引用素材已删除、无权访问、加载失败时，禁止提交任务，并明确指出有问题的参考项；不得静默忽略或自动换成其他候选。
7. 只要直接上游仍处于提交阶段或生成阶段，下游就不能执行；即使上游保留了旧结果，也不能把旧结果当作本次可用输入。
8. 节点提示词非空时，节点提示词是创作指令，直接上游文本作为参考材料。
9. 节点提示词为空且存在有效的直接上游文本时，允许生成；所有直接上游文本按参考区展示顺序合并为创作指令，保留文本之间的分隔，不重复作为参考材料提交。
10. 节点提示词和有效直接上游文本都为空时，普通生成不能提交；图片、视频编辑工具按各自必要参数校验。
11. 文本正文是输出，不自动成为自身输入；生成结果不自动拼接上游原文。

### 4.3 结果更新、候选与历史

1. 文本、视频、单张图片生成成功后，新内容自动覆盖当前结果，旧结果进入历史。
2. 图片一次生成多个结果时，全部有效图片保留在当前节点；新批次成功后默认选择该批次第一张有效图片。
3. 第一张按返回的稳定结果索引确定，不按缩略图加载完成顺序确定。用户随后可在本批次内改选。
4. 再次创作形成新批次时，新批次取代上一批次的当前地位；上一批次的全部候选及选择记录保留到历史。
5. “覆盖”只表示更新当前输出，不是删除旧结果；节点不得因生成新结果而丢失旧批次或历史。
6. 候选没有独立画布端口，不能拆出、拖出或复制为独立节点。节点整体复制与候选拆出是不同能力。
7. 收起节点时显示当前结果；同批次未选候选及历史结果不对外输出。
8. 一个节点最多只有一个有效当前结果；首次尚无成功结果时允许没有当前结果。
9. 预览、展开、浏览历史或浏览候选不得隐式更换当前结果；只有明确的“设为当前结果”操作才更新节点输出。
10. 从历史恢复结果后，不改变该结果原本的批次排序，不自动运行下游。

### 4.4 上传与编辑

1. 节点内“上传替换”一次只允许选择一个文件；新素材上传成功后成为当前结果，旧结果及原有候选批次保留到历史。
2. 上传替换不添加参考、不改变节点连线，也不把上传素材伪装成提示词生成结果。
3. 批量素材导入仍走独立入口，保持现有行为；不能把批量导入直接当作节点内多候选上传。
4. 图片编辑、视频编辑属于本次范围。编辑成功后结果回到原节点并自动替换当前结果，旧结果进入同一历史，触发下游更新标识。
5. 编辑失败时保留并恢复展示旧结果，提示失败，不生成虚假当前结果。
6. 编辑使用被编辑的原素材作为显式输入，不受“自身结果不自动作为生成参考”的限制。
7. 编辑提交后的任务锁定、生成动画、失败恢复、删除取消和下游保护，与普通生成任务一致。

### 4.5 下游读取与更新标识

1. 所有输出连线连接节点本身，只读取当前结果，不读取整批候选或历史。
2. 下游执行使用提交时的执行快照，并记录具体上游结果身份或版本。
3. 上游当前结果更新后，不自动运行下游，也不删除下游已有结果。
4. 直接上游当前结果变化时，只标记直接下游；不跨层传播。例如甲 → 乙 → 丙，甲更新只标记乙；乙当前结果实际更新后才标记丙。
5. 下游只有生成成功，且本次使用的全部直接上游版本仍与当前一致时，才清除“上游内容已更新”标识。
6. 下游失败，或执行期间直接上游再次变化，均保留标识。
7. 从历史恢复结果不重新计算或清除“上游内容已更新”标识。
8. 该标识需要后端记录并返回稳定版本信息，不能用图片地址或临时 URL 判断；属于前后端协作项。

### 4.6 任务生命周期、锁定与依赖保护

1. 服务端任务 ID 是解锁生成阶段的边界；前端本地请求编号不能冒充任务 ID。
2. 任务 ID 返回前，只锁定当前节点及其关联连线；不禁用整张画布，其他节点仍可操作。提交失败后退出提交锁定并提示失败。
3. 任务 ID 返回后，允许修改当前节点提示词、参数和连线，但只影响下一次执行；本次任务继续使用提交快照。
4. 生成或编辑期间，节点结果区域展示动画，不展示旧结果；旧结果数据保留，不因进入加载态而丢失。
5. 生成或编辑期间不能替换素材、切换当前结果或恢复历史结果；历史入口也不能绕过限制。
6. 同一节点同时只能执行一个生成或编辑任务；任务结束前禁止再次提交。不同节点在满足依赖限制时可以并行执行。
7. 下游提交后、取得服务端任务 ID 前，锁定其直接上游当前输出：禁止上游重新生成、上传替换、切换候选、恢复历史结果、删除上游节点或删除包含上游节点的分组。
8. 上述依赖锁定提示统一为：“操作可能导致下游丢失参考素材，请稍后再试”。
9. 同一个上游被多个正在提交的下游引用时，要等这些下游都取得任务 ID 或提交失败后，才解除依赖锁定。
10. 下游取得任务 ID 后，上游可以重新生成；下游继续使用已提交的输入快照完成本次任务，不被上游新结果改写。

### 4.7 删除与取消

1. 正在执行任务的节点允许删除；删除时同时向后端发送取消任务指令。
2. 尚未取得任务 ID 时也允许删除；若服务端随后返回任务 ID，系统自动补发取消指令。
3. 取消任务失败不向用户提示、不要求重试；不恢复已删除节点。
4. 迟到结果不得重新创建已删除节点，也不得写回其他节点。
5. 删除包含运行任务的节点分组时，要处理组内所有运行任务的取消。
6. 依赖锁定优先于删除：如果节点被尚未取得任务 ID 的下游引用，仍禁止删除该节点或包含它的分组，并显示依赖锁定提示。

## 5. 状态与异常边界

| 场景 | 已确认规则 | 仍需设计或联调 |
|---|---|---|
| 无结果首次执行 | 不新增节点；期间展示动画；成功后建立候选并默认第一张有效结果 | 动画和空态样式 |
| 有结果再次执行 | 成功后自动覆盖当前输出，旧结果入历史；图片多结果默认第一张有效图片 | 是否自动展开最新批次 |
| 生成动画期间 | 结果区域展示动画，不展示旧结果；旧数据保留 | 动画表现形式 |
| 全部失败 | 停止动画；有旧结果则恢复展示并提示失败；无旧结果则显示无结果及失败提示 | 提示与重试入口样式 |
| 部分图片成功 | 保留成功候选，默认第一张有效图片为当前结果，提示实际成功数量 | 是否提前展示中途结果；补生成是否建立新批次 |
| 同节点执行中 | 不允许重复提交；允许修改下一次草稿和连线 | 无 |
| 多节点并发 | 不同节点可并行，但受依赖锁定和上游生成状态限制 | 统一并发上限是否调整 |
| 任务 ID 返回前 | 只锁当前节点及关联连线；其他画布操作可用；提交失败解锁 | 锁定与禁用样式 |
| 任务 ID 返回后 | 可改草稿和连线，只影响下一次执行，本次快照不变 | 运行配置与草稿的视觉区分 |
| 生成期间替换或切换 | 禁止，历史入口也不能绕过 | 入口隐藏或禁用样式 |
| 直接上游生成中 | 下游禁止执行，即使上游保留旧结果也不可用 | 禁止执行原因提示 |
| 下游提交、任务 ID 前 | 锁定其直接上游输出及删除操作 | 提示放置位置 |
| 下游已取得任务 ID | 上游可重新生成；下游使用快照完成本次任务 | 下游是否提示上游已变化 |
| 上游当前结果更新 | 只标记直接下游，不跨层传播 | 标识样式 |
| 下游成功且输入版本一致 | 清除上游更新标识 | 后端版本接口 |
| 下游失败或上游再次变化 | 保留更新标识 | 无 |
| 历史结果恢复 | 不重新计算或清除更新标识；不自动运行下游 | 恢复操作反馈 |
| 缺失或无效参考 | 禁止提交并定位问题参考，不静默忽略 | 错误展示位置 |
| 上传失败 | 保留旧结果，不把临时地址当永久结果 | 上传失败提示 |
| 上传替换成功 | 新素材成为当前结果，旧结果和批次入历史 | 与编辑工具的入口区分 |
| 删除运行节点 | 允许删除并发送取消；无任务 ID 时后续补取消；取消失败不提示 | 无用户提示属已确认 |
| 删除被依赖的上游 | 任务 ID 前禁止；删除分组同样禁止 | 提示复用依赖锁定文案 |
| 迟到回调或重复回调 | 幂等写入，不产生虚假成功项；已删除节点不复活 | 无 |
| 离开画布或刷新 | 请求与画布／节点绑定，不写错画布；不承诺刷新续跑 | 是否支持恢复运行 |
| 撤销／重做 | 不能让已返回结果关联到错误请求 | 历史恢复操作是否可撤销 |
| 循环连接 | 自引用不允许；更长环是否禁止另行确认 | 是否禁止所有有向环 |

## 6. 设计需求

现有单素材节点样式不能覆盖候选、历史、任务状态和依赖提醒，设计应沿用项目设计系统。

### 6.1 节点收起态

- 展示当前结果、候选数量、展开入口、无结果状态、生成动画和失败状态。
- 编辑中、提交中、生成中、失败、上游已更新需要可区分。
- 当前结果必须唯一可辨认，不能把历史结果或未选候选误显示为当前结果。

### 6.2 节点内临时浮层

已确认采用节点内临时浮层，不使用侧面板，不改变节点原有尺寸、位置、连线锚点或分组边界，也不自动移动周围节点。

- 浮层以当前节点为起点，允许临时遮挡附近内容。
- 只有一个统一浮层，不设置“当前批次／历史记录”页签。
- 当前批次和全部历史结果在同一列表展示，按批次从新到旧排列，最新结果在前。
- 当前结果有明确标识；任意历史结果可通过“设为当前结果”恢复，浏览不会隐式切换。
- 历史较多时滚动并按批次分页加载；空态、加载中、加载失败需要设计。
- 图片支持多结果比较；文本、视频采用适合各自媒体的预览和历史查看方式，不能直接套图片网格。

### 6.3 其余必需的交互状态

| 设计项 | 必须说明 |
|---|---|
| 选择当前结果 | 当前标识、候选内改选、历史恢复、操作后的反馈 |
| 生成及错误 | 动画替代旧结果、全部失败、部分成功数量提示、首次无结果错误 |
| 上传与参考 | 节点内单文件替换、添加参考、独立素材导入三个入口的区分 |
| 输入状态 | 草稿已改未执行、本次执行快照、模型不可用、超限或缺失参考 |
| 下游更新 | “上游内容已更新”位置、内容、清除条件 |
| 分享页 | 只展示当前结果，不展示候选和历史，不提供修改或生成操作 |

### 6.4 设计验收矩阵

覆盖 1 张、2 张、多张、不同宽高比、当前批次无结果、旧批次有结果、部分成功、全部失败、大量历史、低缩放、展开组、折叠组、窄窗口、长文本和视频。文字、工具和连线不得相互遮挡；浮层不得破坏节点尺寸和端口位置。

## 8. 数据、接口与后端协作

### 8.1 数据职责

字段名称由实现确定，以下只表达职责：

| 数据 | 必要信息 |
|---|---|
| 草稿 | 提示词、模型、参数、输入关系 |
| 任务 | 服务端任务 ID、本地提交标识、状态、取消状态、提交时间、结束时间 |
| 执行快照 | 实际模型、参数、提示词、直接输入节点／结果版本、资产编号或文本版本 |
| 候选批次 | 稳定批次编号、任务编号、时间、状态、请求数量、结果列表 |
| 结果 | 稳定结果编号、所属批次、返回索引、类型、内容或永久资产编号、来源 |
| 当前结果 | 当前选定结果编号及可区分输出变化的版本 |
| 历史记录 | 全部批次及曾用当前结果的列表，支持分页和从新到旧排序 |
| 依赖记录 | 下游执行时使用的直接上游结果身份或版本 |
| 上游更新标识 | 标识状态、触发版本、清除依据；后端持久化 |
| 临时状态 | 浮层、预览、生成动画、本地控制器；不得持久化函数或临时地址 |

### 8.2 保存与恢复

- 必须恢复草稿、任务快照、候选批次、历史、当前结果和依赖版本。
- 永久资产编号是保存依据，临时预览地址不能代替；候选和历史资产同样需要解析。
- 任一保留结果无法持久化时，不得静默丢弃后提示保存成功。
- 结果历史不得只依赖撤销栈；撤销记录过期或被清理，不能导致产品历史消失。
- 保留全部历史，不自动清理；浮层滚动时按批次分页加载。
- 分享、旧文件、旧画布和复制粘贴必须与新增结构兼容，不能静默降级覆盖。

### 8.3 必须由后端确认

1. 新增候选、历史、当前结果、执行快照、依赖版本字段能否通过现有文档协议完整保存和返回。
2. 文档字段白名单、大小限制、历史数量限制和版本迁移策略；超限必须明确失败，不能裁掉历史后返回成功。
3. 服务端任务 ID 的真实返回时机，以及按提交标识取消尚未创建任务的能力。
4. 非当前结果的资产是否仍能被授权解析；分享接口是否排除未公开候选和历史。
5. 视频结果永久资产编号的字段和接线；当前前端视频回填可能缺少 asset_id。
6. “上游内容已更新”标识所需的输入版本和清除依据字段。
7. 历史分页、排序、总数量、复制和导入导出的接口行为。

## 9. 跨功能边界

- 复制整个节点包含配置、全部候选、历史批次和当前结果选择；副本数据独立，不复制正在执行的任务。
- 分享只公开当前结果；候选、历史及其资产地址不得出现在公开响应或页面，必须由后端强制隔离。
- 图片、视频编辑结果回到原节点；生成、编辑、上传替换共用当前结果和历史规则。
- 删除正在执行的节点允许，取消失败不提示；被下游锁定的上游节点及其分组禁止删除。
- 上游内容更新只标记直接下游；标识由后端持久化，历史恢复不重新计算或清除标识。
- 候选展开不增加节点数量，不影响导航、节点编号、端口和自动布局统计。
- 音频、独立素材节点、批量导入和现有工作流编辑功能不得因共享模块改动而回归。
- 刷新续跑没有确认；关闭页面不能承诺任务继续执行或回来自动回填。

## 10. 验收清单

### 10.1 已确认规则验收

1. 空图片节点单张生成：节点和连线数量不变，成功结果成为当前结果。
2. 空图片节点多张生成：全部有效图片在当前节点，默认第一张有效图片。
3. 缩略图加载顺序变化不改变默认选择，索引缺项不错配。
4. 文本、视频和单张图片再次生成成功：当前输出自动更新，旧结果进入历史。
5. 图片多结果再次生成：新批次默认第一张有效图片，取代上次选择；旧批次保留。
6. 生成或编辑期间显示动画，不显示旧结果；全部失败恢复旧结果并提示失败；部分成功保留成功候选、默认第一张有效图片并提示成功数量。
7. 节点内浮层从新到旧展示当前及历史结果；浏览不切换；明确恢复才切换；不改变批次排序，不自动运行下游。
8. 候选无独立端口，不能拆出；取消旧的多结果节点创建逻辑。
9. 上游多候选时，下游只接收当前结果；切换当前结果不改线、不自动运行下游。
10. 上传替换单文件成功后更新当前结果并保留旧历史；批量导入仍走独立入口。
11. 图片、视频编辑成功后回到原节点并更新历史；失败保留旧结果。
12. 任务 ID 返回前只锁当前节点及连线；返回后允许改下一次草稿和连线。
13. 任务 ID 返回后不能重复提交、替换或切换当前结果；同一节点同时只有一个任务。
14. 直接上游生成中时下游禁止执行；下游任务 ID 返回后上游可重新生成。
15. 下游任务 ID 返回前锁定其直接上游输出和删除操作，提示“操作可能导致下游丢失参考素材，请稍后再试”。
16. 上游当前结果更新后只标记直接下游；下游成功且输入版本一致后清除。
17. 缺失或无效参考禁止提交并定位问题项。
18. 节点提示词非空时作为指令；为空且有上游文本时按显示顺序合并为指令；两者都为空时普通生成拦截。
19. 删除运行节点发送取消；无任务 ID 时后续补取消；取消失败不提示；迟到结果不复活节点。
20. 复制整个节点包含全部候选和历史，不复制运行任务。
21. 分享页只显示当前结果，不显示候选、历史或未公开资产。

### 10.2 一致性与回归验收

1. 快速重复提交、迟到回调、节点删除和画布切换不会重复写入或串写其他节点。
2. 执行记录与实际提交对应，后续草稿编辑不能改写旧记录。
3. 模型切换后的非法输入有明确反馈；首尾帧展示顺序与实际提交相同。
4. 旧画布及旧导出文件不丢内容和连接，不自动合并历史节点。
5. 复制、粘贴、撤销、重做、导入、导出不产生无效当前结果或共享可变状态。
6. 资产恢复失败明确显示，不自动换当前结果；分享页只展示已确认公开内容。
7. 分组、导航、预览、下载及现有音频功能正常；候选不混入节点统计。
8. 所有已确认的锁定、依赖、失败、部分成功和删除场景按第 5 节验收。

视觉效果由需求方手动验证，不自动打开浏览器。实施后按仓库要求执行定向检查、构建和必要逻辑测试；本文件不代表测试已通过。

## 12. 建议实施顺序

1. 产品和设计确认第 11 节剩余事项；前后端核实保存协议、任务 ID、取消和版本接口。
2. 先建立统一数据职责：草稿、任务快照、批次、结果、当前结果、历史、依赖版本和临时状态。
3. 打通保存恢复、旧数据兼容、资产编号和历史分页；未打通前不发布只显示多图但刷新丢失历史的版本。
4. 统一输入解析、提示词规则、缺失参考拦截和上下游依赖锁定。
5. 改造图片单张／批量任务，再改造文本、视频、上传替换和编辑工具。
6. 接入节点浮层、当前结果选择、历史恢复、上游更新标识。
7. 补齐复制、撤销、文件、分组、分享和音频回归。
8. 执行第 10 节全部验收，并以真实后端联调结果为准，不以静态代码推断替代联调。
