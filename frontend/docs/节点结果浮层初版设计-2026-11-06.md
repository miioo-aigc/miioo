# 节点结果浮层初版设计

日期：2026-11-06。状态：已接入画布节点；下文初版记录保留为设计背景，冲突处以本节最新确认规则为准。视觉由需求方手动验收；未打开浏览器，未提交或推送。

## 最新确认规则

- 文本节点不显示历史记录、替换入口；图片、视频、音频显示媒体替换入口，有结果历史时显示查看入口。不删除已有文本内部结果数据。
- 两个入口位于卡片内部右上角，顶部、右侧边距各 8px，替换在历史左侧；缩小时随画布缩小，放大时不超过原尺寸。
- 替换下拉菜单复用本地上传、资产库选择，仅允许单个同类型素材；视频替换不得混入图片或音频参考。原节点身份、连线、位置保留。
- 音频与图片、视频相同：新结果覆盖原节点，旧结果保留历史；可试听历史音频并恢复为唯一当前结果。
- 浮窗宽 340px、高 600px，内部滚动，优先在历史按钮右侧间隔 8px、顶部对齐；右侧不足回退左侧，始终约束到可视视口内。
- 图片两列，图片和视频预览槽为正方形，按实际比例完整显示，长边撑满、短边留白。音频单列原生试听控件，不自动播放。
- 左上角复用复选框恢复结果，实际仍是单选，不支持取消成空定稿；移除底部操作按钮及结果编号文字。
- 标题仅显示节点名；批次标题左对齐、时间右对齐；隐藏最新/历史批次标签和普通结果数量，部分成功提示单独换行保留。
- 提交锁定禁止两个入口；生成、编辑、上游保护及上传期间允许浏览历史，但不能替换或切换当前结果。上传失败保留旧内容。
- 本节为前端实现契约，不表示后端取消任务、完整历史分页及持久化接口已经联调。

## 设计与边界

目标是让用户在保持节点身份、尺寸、位置和连线不变的前提下，比较当前及历史结果并明确恢复。统一列表的优势是避免查找结果时来回切换；主要风险是浏览与定稿混淆、媒体失效以及运行任务期间误改输出。因此当前标识只读取外部状态，浏览永不写结果，设为当前必须显式点击且经过外部锁定与本体就绪检查。关键变量是宿主提供的任务锁定、资产授权解析状态及真实分页能力，不以视觉选择代替这些状态。

需求方已明确授权缺失设计由实现者决定，本版直接采用以下规则，不再等待视觉确认：

- 只有一个非模态临时浮层，当前及历史共用一条列表，不设页签、候选独立面板或拆出节点入口。主代理通过单一活动节点身份控制只挂载一个打开的实例。
- 挂载到文档主体，固定定位在节点视口矩形下方，空间不足向上，再约束到视口。脱离画布缩放和节点布局，不改变端口、分组边界或周边节点位置。
- 宽度上限 640 像素，高度上限 720 像素，视口边缘留 12 像素。标题固定，内容滚动。窄于 480 像素时图片网格改一列。
- 图片为两列比较、4:3 固定预览槽，完整适配不裁切；文本单列、保留换行、正文区域最高 280 像素且可聚焦滚动；视频单列、16:9 槽位、原生播放控件、不自动播放。
- 批次直接复用 getCanvasResultHistory，由新到旧。当前标识直接复用 getCanvasCurrentResult，恢复旧结果不改变批次排序；结果在批次内保留协议索引顺序。
- 复用 Button、ModalCloseButton、MediaLoadStatus 和现有图标库。背景、描边、字体、圆角、状态色沿用现有变量，无全局变量变动。批次为无框分组，仅结果项使用边框，圆角 8 像素。
- 不用 CanvasMediaPreview：它会创建第二个全屏浮层；不用 CanvasVideoPlayer：它含画布拖动层和悬停播放，且存在对话框时阻止播放。AsyncImagePreview 未暴露加载状态回调，无法据本体加载结果禁用切换；本版原生图片事件配合现有媒体反馈组件。
- 已检索组件资产清单、设计系统及相关组件。规则引用的 docs/architecture/feature-development.md 在当前仓库不存在，按现有组件架构与资产清单处理归属。

## 属性契约

默认导出：src/components/canvas/CanvasNodeResultsPopover.jsx。样式随组件导入，无需改目录入口。

| 属性 | 类型与含义 |
|---|---|
| open | 布尔值，默认关闭；宿主控制开关及唯一打开实例 |
| results | CanvasNodeResults.js 的有效第一版完整结果状态；打开时必传，包含有效 currentResultId、batches 和 selections |
| nodeName | 中文节点名称，默认“节点”，用于可访问标题 |
| anchorRect | 节点视口像素矩形，使用 left、top、bottom；宿主在平移、缩放、节点移动时重新计算并传入，不传则从视口左上安全区域开始 |
| returnFocusRef | 可选入口元素引用；关闭或卸载后返回该元素，否则返回打开时的活动元素；已移除的元素跳过 |
| mediaByResultId | 以结果身份为键的解析记录，值为 { status, src?, poster?, message? }；不接受地址作为结果身份 |
| generating / editing | 当前节点生成或编辑的提交及执行阶段均传真，禁止切换；宿主负责映射实际任务状态 |
| upstreamProtected | 当前节点作为上游受下游提交保护时传真；统一显示“操作可能导致下游丢失参考素材，请稍后再试” |
| selectionPending / selectionError | 外部切换等待及错误；等待禁用全部切换，错误独立展示 |
| loading / error | 首次读取加载及错误；加载优先，隐藏结果列表；错误显示显式重试 |
| hasMore / loadingMore / loadMoreError | 外部真实分页状态；保留已有列表，更多加载失败提供重试，不虚构总数或游标 |
| onClose() | 关闭按钮或退出键发出意图；宿主必须设 open 为假 |
| onSelect(resultId) | 仅显式切换动作调用，组件不调用写函数、不乐观修改定稿；缺少回调时禁用 |
| onLoadMore() | 加载更多或重试更多；缺少回调或正在加载时禁用，不自动请求 |
| onRetry() | 首次读取失败的重试，可选 |
| onRetryMedia(resultId) | 可选媒体恢复回调；同时重建本地媒体加载尝试；外部无权或不存在的素材不能由本地重试恢复授权 |

媒体状态为 ready、loading、error、unavailable。缺少记录视为不可用。ready 必须有可访问的 src，且图片加载或视频首帧成功后才能选择；加载失败立即禁选。文本依照现有协议校验为非空正文，按纯文本展示，不执行内容。媒体换源会重建预览会话，旧源的就绪状态不继承。当前结果即使失效也保留当前标识，不自动换为其他结果。

生成、编辑时本浮层仍允许查看历史，但禁止改选；节点自身生成时用动画替代旧结果的行为由后续节点整合负责，本组件不修改节点展示。全部失败的终止批次不会被现有协议保留，宿主通过 error 呈现首次失败，或 selectionError 呈现有旧结果时的错误；不可伪造成功结果。部分成功直接使用已有批次状态和数量。

## 主代理整合

1. 用单一活动节点身份控制唯一浮层，传该节点结果状态和屏幕坐标；在画布更新时同步坐标。关闭或切换节点时卸载旧实例。
2. 由已有资产解析层提供每个结果的授权地址及解析状态，不把地址写回永久结果协议。
3. onSelect 收到稳定结果身份后，重新核查最新任务状态及依赖保护，再使用 selectCanvasNodeResult 更新受控结果；成功后回传 results。后端写入、历史记录、依赖标识及并发防重复由主代理负责。
4. 真分页只在宿主接通后启用 hasMore；首版内存全部批次可直接传 results 并设 hasMore 为假。组件不切片模拟分页、不生成游标、不请求后端。分页合并后的 results 仍必须满足协议，尤其不能丢失当前结果引用及选择记录。
5. 宿主提供 loading、error 和切换反馈，保持回调幂等；读写请求、节点和画布身份隔离不由组件承担。

## 可访问性与画布隔离

单一非模态对话框有节点名称标题，打开聚焦浮层，退出键关闭并阻止向画布传播，关闭后焦点返回入口。保留正常键盘遍历，不锁整个画布焦点。中文输入法组合期间退出键不关闭。图片替代文字、视频名称、正文名称、重试和切换动作均有可访问名称；当前结果由文本与描边双重表达。

浮层阻止指针、鼠标按下、触摸、点击、双击、滚轮及键盘事件传播，保留内部滚动和播放控件默认操作。原生拖出被取消，并带现有画布隔离类名；宿主不得在文档捕获阶段抢先执行画布快捷键或缩放。没有遮罩和自动外部点击关闭，关闭由关闭按钮或退出键完成。
