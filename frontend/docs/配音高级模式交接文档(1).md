# 配音功能页面 · 高级模式交接文档

> 适用范围：创作模块 → 配音功能 → 「专业模式」弹窗（叠加效果器 / voice_modify 相关能力）。
> 事实源：`frontend_new/src/pages/DubbingStudio.jsx`、`frontend_new/src/api/creation.js`、`backend/app/services/tts.py`、`backend/app/routers/creation.py`、MiniMax 官方 `t2a_v2` 协议。
> 维护日期：2026-08-21。

---

## 1. 功能概述

配音高级模式（DubbingAdvancedModal）是创作模块配音页的「专业模式」弹窗，提供官方完整参数：
- 文稿输入：直接输入 / 上传 `.txt` / `.zip` 文本包（长文本走 MiniMax 异步任务）
- 文本增强：情绪标签、停顿标签、语气词标签（插入 `{}` / `[pause]` 等标记）
- 模型选择：MiniMax speech 系列（`speech-2.8-hd` / `speech-2.8-turbo` 等），经 OneLinkAI 网关透传
- 音色选择：打开 DubbingVoiceModal（语音库：官方音色 / 复刻音色 / 收藏音色）
- 语速 / 声调 / 音量（`voice_setting`）
- **叠加效果器（voice_modify）**：3 个声学滑块 + 4 个环境特效

## 3. 叠加效果器（voice_modify）详情

### 3.1 UI 控件

| 控件 | 字段 | 范围 | MiniMax 语义 |
|------|------|------|--------------|
| 低沉 ↔ 明亮 | `pitch` | -100 ~ 100 | 音高调整；负=低沉，正=明亮 |
| 力量感 ↔ 柔和 | `intensity` | -100 ~ 100 | 强度调整；负=刚劲，正=轻柔 |
| 磁性 ↔ 清脆 | `timbre` | -100 ~ 100 | 音色调整；负=浑厚，正=清脆 |
| 空旷回声 | `sound_effects` | `spacious_echo` | 环境音效（**单选枚举**） |
| 礼堂广播 | `sound_effects` | `auditorium_echo` | 同上 |
| 电话失真 | `sound_effects` | `lofi_telephone` | 同上 |
| 电音 | `sound_effects` | `robotic` | 同上 |

> ⚠️ 2026-08-21 修复：旧枚举值 `hall_reverb / auditorium / telephone / electronic` 与 MiniMax 官方枚举不符，会导致上游参数错误；已改为官方枚举。
> ⚠️ `sound_effects` 是**单选**（MiniMax 官方：单次仅能选择一种），此前前端多选数组 `join(',')` 必 400，已改为单选字符串。

### 3.2 组装逻辑（submit，DubbingStudio.jsx `:391`）

```js
// 只保留非默认值
const nonDefaultModify = Object.fromEntries(
  Object.entries(voiceModify).filter(
    ([key, value]) => key === 'soundEffect' ? Boolean(value) : Number(value) !== 0
  )
);
// payload 中的 voice_modify（后端契约 snake_case）
voice_modify: Object.keys(nonDefaultModify).length ? {
  ...(nonDefaultModify.pitch      !== undefined ? { pitch: Number(nonDefaultModify.pitch) } : {}),
  ...(nonDefaultModify.intensity  !== undefined ? { intensity: Number(nonDefaultModify.intensity) } : {}),
  ...(nonDefaultModify.timbre     !== undefined ? { timbre: Number(nonDefaultModify.timbre) } : {}),
  ...(nonDefaultModify.soundEffect ? { sound_effects: nonDefaultModify.soundEffect } : {}),
} : undefined,
```

## 4. 参数链路

### 4.1 前端 → API 层

`DubbingAdvancedModal.submit` 构造 payload → `onGenerate(payload)` → `CreationPage.handleGenerate` → `apiGenerateCreation(params)`（`creation.js:893`）→ 配音分支组装 `dubbingBody`（`creation.js:1046`）：

```js
const dubbingBody = {
  text: params.prompt || params.text,
  prompt_raw: params.prompt || params.text || undefined,
  model: params.model || undefined,
  speed: params.speed ?? 1.0,
  emotion: params.emotion || undefined,
  voice_id: params.voice_id || params.voiceId || undefined,
  reference_audio_url: referenceAudioUrl || ...,
  voice_modify: params.voice_modify || undefined,   // 2026-08-21 补透传
  session_id / shot_id / project_id,
};
```

- 短文本（≤ 500 字符）→ `POST /api/creation/audios/generate`（同步）
- 长文本（> 500 字符，且模型为 MiniMax speech-*）→ `POST /api/creation/audios/generate-async`（异步任务，前端轮询 `/audios/tasks/{task_id}`）

### 4.2 后端

| 接口 | 文件:行 | 说明 |
|------|---------|------|
| `POST /audios/generate` | `creation.py:7436` | 同步 TTS；`CreationAudioGenerateRequest`（继承 `TTSAdvancedOptionsMixin`）|
| `POST /audios/generate-async` | `creation.py:7751` | 异步配音任务；仅支持 MiniMax 官方 voice 模型 |
| `GET /audios/tasks/{task_id}` | `creation.py:7983` | 异步任务轮询 |

后端解析流程（同步）：
1. `get_user_model_provider_credentials(category="voice", requested_model=req.model)` → `(api_key, base_url, provider_type, model_id)`
2. `effective_requested_voice_id = req.voice_id or 参考音频绑定音色 or "zh-CN-XiaoxiaoNeural"`（⚠️ 见已知问题 6.2）
3. `resolve_audio_voice_context`：查语音库 → 归一 `upstream_voice_id`（`audio_voice_context.py:62`）
4. `build_tts_provider_options` → `tts_service.generate(...)`（`tts.py:200`）
5. 落盘 `persist_if_external` → 返回 `audio_url` + clip 记录

### 4.3 TTS 协议路由（tts.py:216-324）

| provider_type | 模型 | 请求 URL | payload 协议 |
|---------------|------|----------|--------------|
| `minimax` | 任意 | `https://api.minimaxi.com/v1/t2a_v2` | MiniMax 原生（text + voice_setting） |
| `onelink` + `speech-*` | speech-2.8-* | `https://api.onelinkai.cloud/minimax/v1/t2a_v2` | MiniMax 原生（网关透传，/minimax 前缀） |
| `onelink` + 其他 | tts-1 等 | `.../v1/audio/speech` | OpenAI 兼容（input + voice） |
| `aiping` | - | `aiping.cn/api/v1/audio/speech` | AI Ping 原生 |
| `volcengine` | - | 火山方舟 | Volcengine 原生 |

MiniMax 原生 payload（use_minimax_native 分支）：

```json
{
  "model": "speech-2.8-turbo",
  "text": "你好欢迎使用mio",
  "stream": false,
  "voice_setting": { "vol": 1, "pitch": 0, "voice_id": "...", "speed": 1.0 },
  "voice_modify": { "pitch": 30, "intensity": 0, "timbre": 0, "sound_effects": "spacious_echo" }
}
```

### 4.4 上游

- 网关：OneLinkAI `https://api.onelinkai.cloud`（MiniMax 能力前缀 `/minimax`，见 `app/utils/onelink_base_url.py:122`）
- 原生协议：MiniMax `/v1/t2a_v2`（同步）、`/v1/t2a_async_v2`（异步）
- `voice_modify` 官方支持：pitch/intensity/timbre 各 [-100,100]；`sound_effects` 枚举 `spacious_echo | auditorium_echo | lofi_telephone | robotic`

## 5. 核心字段契约（后端 schema：`backend/app/schemas/tts.py`）

| 请求字段 | 类型 | 说明 |
|----------|------|------|
| `text` | str | 必填，≤10000（同步）/ 长文本走异步 |
| `model` | str | 配音模型 ID（如 `speech-2.8-turbo`） |
| `voice_id` | str | 音色 ID；空时后端兜底默认音色 |
| `speed` | float | 语速 0.5~2.0 |
| `voice_setting` | obj | voice_id / speed / vol(>0~10) / pitch(-12~12) / emotion / text_normalization / latex_read |
| `audio_setting` | obj | sample_rate / bitrate / format / channel / force_cbr |
| `pronunciation_dict` | obj | 注音词典 `{tone: ["燕少飞/(yan4)..."]}` |
| `timbre_weights` | list | 音色权重 `[{voice_id, weight(1-100)}]` |
| `language_boost` | str | 语种增强 |
| `voice_modify` | obj | **pitch / intensity / timbre / sound_effects（本次交接核心）** |
| `subtitle_enable` / `subtitle_type` | bool/str | 字幕 |
| `output_format` | str | 输出格式 |
| `aigc_watermark` | bool | 水印 |
| `stream` / `stream_options` | bool/obj | 流式（当前同步接口不支持流式） |

## 6. 已知问题与修复记录

### 6.1 ✅ 已修复（2026-08-21）

| 问题 | 根因 | 修复 |
|------|------|------|
| 502「OneLinkAI 请求参数不合法」 | 未选音色 → 后端兜底 `zh-CN-XiaoxiaoNeural`（Azure 音色），MiniMax 不识别 | 前端普通/专业模式生成前校验 `voice.id`，空则 toast「请先选择音色」并中止（DubbingStudio.jsx:643、:391） |
| 叠加效果器全部不生效 | `dubbingBody` 未透传 `voice_modify` | `creation.js:1057` 补 `voice_modify: params.voice_modify \|\| undefined` |
| 特效按钮上游报错 | 枚举值写错（hall_reverb 等 ≠ MiniMax 官方值） | `SOUND_EFFECT_PRESETS` 改为官方枚举（DubbingStudio.jsx:44） |
| 多选特效必 400 | MiniMax `sound_effects` 单选枚举，前端却 join 逗号 | `soundEffects[]` 多选 → `soundEffect` 单选字符串 |

### 6.2 ⚠️ 遗留（未处理）

1. **后端兜底音色不兼容**：`creation.py:7488` 兜底 `zh-CN-XiaoxiaoNeural` 对 MiniMax speech-* 模型无效。建议改为 MiniMax 兼容音色（如 `Chinese (Mandarin)_Lyrical_Voice`）或 speech-* 无音色直接 400。
2. **dubbingBody 仍漏透传高级字段**：`audio_setting / pronunciation_dict / timbre_weights / language_boost / subtitle_enable / subtitle_type / output_format / aigc_watermark / stream / stream_options` 在前端 `dubbingBody` 中未带上（DubbingAdvancedModal 已构造这些字段但被丢弃）。**专业模式下这些参数目前发不出去**，如需启用需在 `creation.js` dubbingBody 逐项补透传。
3. **普通模式无 voice_modify 入口**：普通模式仅 voice_id/语速/声调/音量，符合设计。
4. **上游未验证项**：OneLinkAI `/minimax/v1/t2a_v2` 的 voice_modify 透传是否完全兼容建议实测一次（见 §7 curl）。
