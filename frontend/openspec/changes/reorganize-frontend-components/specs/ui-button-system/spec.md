## ADDED Requirements

### Requirement: 基础按钮必须提供统一视觉契约
基础按钮组件 SHALL 支持设计规范定义的变体、尺寸、图标、禁用和加载状态，并优先使用项目 Token 类名，不得在页面中重复实现同一套基础按钮视觉。

#### Scenario: 使用主操作按钮
- **WHEN** 页面需要普通主操作
- **THEN** 页面通过基础 Button 的公开接口选择变体和尺寸，而不是复制完整原生 button 样式

#### Scenario: 按钮加载或禁用
- **WHEN** 按钮处于加载或禁用状态
- **THEN** 按钮 MUST 阻止重复触发，并展示与现有设计规范一致的状态

### Requirement: 业务语义与基础视觉必须分离
基础按钮 MUST 不知道项目 API、页面路由或业务 Store；包含业务请求、权限、确认或 Toast 的动作 MUST 由业务动作组件或页面 Hook 编排。

#### Scenario: 业务按钮调用 API
- **WHEN** 用户点击“生成图片”并需要调用 API
- **THEN** API 调用逻辑位于业务动作组件、Hook 或页面层，基础 Button 只接收通用状态和回调

### Requirement: 按钮迁移必须可追踪
每个页面的按钮迁移 MUST 记录原实现、目标组件、行为差异和验收结果；迁移完成后不得留下未说明的重复基础实现。

#### Scenario: 完成一个页面迁移
- **WHEN** 页面中的按钮完成抽离
- **THEN** 迁移记录包含组件映射、搜索结果、构建/Lint 检查结果和人工关键流程结果
