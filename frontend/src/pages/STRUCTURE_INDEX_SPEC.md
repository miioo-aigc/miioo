# 页面文件结构索引规范

## 目的

对于超过 300 行的页面或组件文件，在文件顶部维护一份「结构索引」。
其作用是让 AI 在读取代码前先建立全局地图，避免因文件过长导致中间内容被忽略。

---

## 索引位置与格式

索引必须是文件的**第一个注释块**，紧贴第一行，使用 JSDoc 格式：

```jsx
/**
 * @file 文件名.jsx
 * @structure-index
 *
 * ─── 分组标题 ──────────── L起始行–结束行
 *   条目名称      说明文字   L行号
 */
```

索引结束后紧接 `import` 语句，中间不插入其他内容。

---

## 必须包含的分组

根据文件实际内容选择，不强求全部出现：

| 分组名 | 包含内容 |
|---|---|
| 全局常量 & 工具函数 | 常量、纯函数、类型定义 |
| 动画注入函数 | 运行时向 `<head>` 写入 keyframe 的函数 |
| 原子 UI 组件 | 无业务逻辑的展示组件 |
| 业务选择器组件 | 含下拉/切换等交互但无数据请求的组件 |
| 核心业务组件 | 含数据请求、复杂状态的组件，需列出子状态和关键函数 |
| 结果/状态展示组件 | 列表、卡片、空态等展示层组件 |
| 主页面入口 | `export default` 所在函数，需详细列出状态、函数、副作用 |
| 更新记录 | 每次修改索引时追加一行 |

---

## 行号标注规则

- 格式统一为 `L行号` 或 `L起始行–结束行`
- 行号指该定义在文件中的**实际行号**（与编辑器行号一致）
- 只标注**定义起始行**，结束行可省略
- 范围跨越较大时（超过 50 行）建议标注结束行

```
// 好的写法
<InputCard>    主输入框   L2100
<InputCard>    主输入框   L2100–L3143

// 避免的写法
<InputCard>    主输入框   L约2100   ← 能精确的就精确
```

---

## 主页面入口的写法

`export default` 组件需要展开内部结构，按以下顺序列出：

```
export default XxxPage()                  L行号
  ├─ [状态] 状态名 / 说明                 L行号
  ├─ [Store] 引用的 store 及解构字段      L行号
  ├─ [函数] 函数名()  一句话说明          L行号
  └─ [副作用] 触发条件简述               L行号
```

状态、函数、副作用各自分组，顺序固定：状态 → 函数 → 副作用。

---

## 更新记录格式

索引末尾固定保留「更新记录」分组：

```
 * ─── 更新记录 ──────────────────────────────────────────────────────
 *   2026-05-28  初始结构索引建立
 *   2026-06-01  新增 <VideoResultCard>（L3600），handleGenerate 移至 L5130
```

每次修改索引时追加一行，格式为 `日期  变更说明`。

---

## AI 执行规则

### 读取文件时
1. 定位文件顶部的 `@structure-index` 注释块
2. 通读索引，建立结构地图
3. 再根据任务需要定位到具体行号阅读代码
4. 若文件无索引，直接阅读代码，**不主动创建索引**（避免打断当前任务）

### 修改文件后
1. 对照代码变更，找到索引中受影响的条目
2. 更新行号和说明
3. 若新增了组件/函数/副作用，在对应分组下追加条目
4. 若删除了内容，从索引中移除对应条目
5. 在「更新记录」末尾追加一行，注明日期和变更内容
6. **索引更新是任务完成的必要条件**，未更新索引视为任务未完成

### 何时需要新建索引
仅在用户明确要求「为这个文件建立结构索引」时才新建。
平时修改代码只需维护已有索引。

---

## 不同规模文件的处理方式

| 文件行数 | 处理方式 |
|---|---|
| < 300 行 | 无需索引，代码本身已足够清晰 |
| 300–800 行 | 建议索引，分组 3–5 个，每组 3–8 条 |
| 800–3000 行 | 必须索引，分组按实际结构划分，主页面入口需展开 |
| > 3000 行 | 必须索引，考虑是否应拆分文件；索引本身不应超过 80 行 |

## 示例（精简版）

```jsx
/**
 * @file StoryboardPage.jsx
 * @structure-index
 *
 * ─── 工具函数 ─────────────────────────────────────────────── L1–L40
 *   formatDuration()    时长格式化                             L12
 *
 * ─── 子组件 ───────────────────────────────────────────────── L42–L380
 *   <ShotCard>          单个镜头卡片（含拖拽）                 L42
 *   <AddShotButton>     添加镜头按钮                           L220
 *   <EmptyState>        空态提示                               L310
 *
 * ─── 主页面入口 ───────────────────────────────────────────── L382–L650
 *   export default StoryboardPage()                            L382
 *     ├─ [状态] shots / loading / activeId                     L390
 *     ├─ [函数] handleAddShot()   调用 apiCreateShot          L420
 *     ├─ [函数] handleDeleteShot() 删除并刷新列表             L440
 *     └─ [副作用] 页面挂载时拉取镜头列表                       L460
 *
 * ─── 更新记录 ──────────────────────────────────────────────────────
 *   2026-05-28  初始索引建立
 */
```
