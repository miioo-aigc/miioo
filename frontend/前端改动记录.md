- 问题：本地登录弹窗点击“发送验证码”时返回 `404 Not Found`
- 原因：
  - 前端请求层使用 `VITE_API_BASE_URL` 拼接接口地址
  - 本地 `.env` 只配置了 `VITE_API_TARGET`，未配置 `VITE_API_BASE_URL`
  - 浏览器实际请求会落到 `undefined/api/auth/send-code`，导致前端 dev server 返回 404
  - 同时本地代理目标错误地指向 `https://localhost:8080`，与后端文档中的本地服务地址 `http://localhost:8000` 不一致
- 处理：
  - 在 `frontend/.env` 中新增 `VITE_API_BASE_URL=`，让本地请求直接走相对路径 `/api/...`
  - 将 `frontend/.env` 中的 `VITE_API_TARGET` 修正为 `http://localhost:8000`
  - 将 `frontend/vite.config.js` 中代理默认目标修正为 `http://localhost:8000`
- 影响范围：
  - 登录验证码发送
  - 本地开发环境下所有依赖 `/api` 和 `/uploads` 代理的前端请求
